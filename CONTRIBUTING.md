# Contributing to NoGira

Thank you for your interest in NoGira.

This repository is the **public installer** for self-hosted NoGira: Docker Compose, documentation, and community/legal files. Application source code is not published here yet.

## What you can contribute today

- Improvements to **README** and **`docs/`** (quick start, deployment, FAQ)
- Fixes to **`docker-compose.yml`** or **`.env.example`** (installer ergonomics)
- Screenshots under **`screenshots/`** (product UI only; no internal architecture diagrams)

Open a GitHub issue or pull request on **nogira-io/nogira** when the repository is public.

## Principles

1. Keep the installer **minimal** — one compose file, few environment variables, obvious quick start.
2. **Security:** do not open public issues for vulnerabilities. Email **security@nogira.co.uk** (see [SECURITY.md](SECURITY.md)).
3. **Commits:** use clear messages (`docs:`, `fix(installer):`, `chore:`).
4. **Trademarks:** follow [TRADEMARKS.md](TRADEMARKS.md).

When application source repositories open under the open-core model, separate contribution guidelines will apply there.

By contributing documentation or installer changes, you agree that NoGira Ltd may use and distribute your contribution under the license applicable to this repository.
