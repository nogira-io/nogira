# NoGira 0.0.3

**Release date:** 2025

## Added

- **Elemental workspace** model — workspace settings, membership shell, basic workspace navigation.
- Workspace **OPEN / PRIVATE** visibility foundations and discovery behaviour.
- Workspace RBAC groundwork (roles, permissions catalog, membership APIs).
- Basic workspace settings wizard and scheme attachment to new workspaces.
- Favorites model (DB-backed) for workspaces and related browse surfaces.

## Changed

- Workspace creation path aligned with template cloning and default schemes.

## Upgrade notes

- Suitable for single-workspace evaluation; multi-workspace polish continued in 0.1.x.
