# NoGira 0.1.7

**Release date:** 2026-05-28

## Added

- **Environment field (development workspaces)** — pick environment from a color-coded dropdown (swatch + label), same visual language as priority.
- **Colored dropdown for custom fields** — create single-select fields with a **Colored dropdown** presentation; manage options with labels and colors.
- **Sprint field (development workspaces)** — link an activity to one or more sprints from **Scrum boards** in that workspace (searchable selector).
- **Sprint rules** — add only planned or active sprints; completed sprints already on the activity stay visible but cannot be removed; helpful empty state when the workspace has no Scrum board.
- **Child activities** — streamlined inline add (Escape to dismiss); choose child type from an icon picker when the scheme allows more than one type.
- **Child table (full activity page)** — status and priority columns; compact display (status tag, priority color dot).
- **Inline child edits** — change assignee, status, or priority from the child table without opening each child; row still navigates to the child when you click key or summary.
- **Coming soon placeholders** — Fix Version and Component show a read-only “Coming soon” state until product/version features ship.

## Changed

- **Child activity popovers** — status and priority pickers open above the page (not clipped behind status history or table scroll).
- **Field option management** — errors and confirmations use in-app modals and toasts instead of browser alerts.
- **Create field form** — validation and API errors shown in a modal.

## Fixed

- **Create field** — “Colored dropdown” UI hint is accepted for single-select fields (no longer rejected by the API).
- **Manage options** — loading and creating options on custom single-select fields (including Environment) uses the correct settings API path.
- **Duplicate option keys** — auto-suffixed keys when adding options with similar labels.
- **Child list data** — priority and status display correctly on the parent activity’s child table.

## Upgrade notes

- **Public installer default version:** edit `docker-compose.yml` tags to `0.1.7` on `nogira-core`, `nogira-ui`, and `nogira-notification-worker`.
- Run `docker compose pull && docker compose up -d`.
- **No manual NoGira SQL** — Prisma `migrate deploy` runs on core startup (includes colored-dropdown UI hint migration).
- **PostgreSQL** stays on `postgres:14` — do not bump to PG 15+ without a PostgreSQL major-upgrade procedure ([deployment.md](../deployment.md)).
- From **0.1.6:** existing volumes compatible; mixed image versions unsupported.
- **Recommended:** deploy **0.1.6** before **0.1.7** if you skipped intermediate tags — priority scheme (0.1.6) is required for development-workspace priority on child rows.
