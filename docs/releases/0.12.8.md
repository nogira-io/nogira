# NoGira 0.12.8

**Release date:** 2026-11-17

**Fix:** email CTA/header org appearance (**NGDEV-369-P6** / **NGF-093**) and deleted-user display (**NGDEV-369-P7** / **NGF-051**). No GIF.

## Added

- Shared email branding resolves org **Primary** / **Sidebar** colours for CTA buttons and header chrome (core + worker; queue + direct mail) (**NGDEV-369-P6**).
- UI letter-face badges: **D** for anonymized users, **U** for Unassigned in selectors/filters (**NGDEV-369-P7**).

## Changed

- Anonymized display name is **`Deleted u-<last 6 of userId>`** (API rewrite for legacy `Deleted User` rows) (**NGDEV-369-P7**).
- Workspace members / assignee / reporter faces use central `UserFaceAvatar` (deleted → **D**, not dicebear).

## Fixed

- Transactional emails no longer hardcode black CTA / gray header — they follow System Appearance.
- Two deleted accounts no longer look like different living people (distinct dicebear faces + identical `Deleted User` label).

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`**.
- Promote matching **core + ui + worker + mcp** images together (email branding + UserLite display).
- No Prisma migration in this release (worker Prisma client may regenerate appearance fields already on InstanceSettings).
- After upgrade: open workspace settings with anonymized members → expect **D** + `Deleted u-XXXXXX`; send a test / collaboration email and confirm CTA/header match Custom appearance.
