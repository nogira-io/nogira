## Added

- **Event Challenge Engine** (**NGF-048**) — **Settings → Challenges** admin list and manage; join tokens and QR (`/register?game=`); presenter modal (open queue, start challenge, phase control, live leaderboard); attendee waiting HUD on `/home`, mission overlay, score toasts, and results/podium.
- **PlatformEvent layer** (**NG-702**) — append-only product events consumed for challenge scoring and CTA tracking.
- **Join-by-token** — profile **Challenges** modal and authenticated join shim; workspace membership with **CHALLENGE** provenance when needed.
- **DRAFT-only delete** on the admin challenge list (typed-name confirm).
- **Admin guide** — [event-challenges.md](../event-challenges.md) (step-by-step for first-time presenters).

## Changed

- **Image set** — core, UI, and notification-worker (and **nogira-mcp** if present) pinned to **0.1.14** together; schema migration applied on core startup.

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.1.14** and `REACT_APP_VERSION` on the UI service, then `docker compose pull && docker compose up -d`.
- Hub must publish **core**, **UI**, **notification-worker**, and **nogira-mcp** at **0.1.14** with the same semver (`cicd-release.sh --version 0.1.14` after dev/uat validation).
- Upgrading from **0.1.13**: bump core, UI, worker, and MCP together; no new Compose service — challenges use existing API/UI containers.
- Presenters need **SYSTEM_ADMIN** for **Settings → Challenges**; attendees join with a normal account via token or registration deeplink.
