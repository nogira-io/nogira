# NoGira 0.3.7

**Release date:** 2026-06-17

**NG-722 wiki Configure block editor** (**NGF-067** / **NGF-079** / **NG-722-P16–P21**) — separator canonicalization, active text-block editing surface, format toolbar polish, inter-block markdown boundaries, accurate block-insert split, and split-after textarea autosize.

**Tracking:** **NG-722-P16**–**P21**, **NGF-067**, **NGF-079**. **Bugs fixed:** **NGB-056**, **NGB-057**, **NGB-058**, **NGB-059**.

## Added

- **Wiki format toolbar sections** — heading levels H1–H4, inline formatting, paragraph alignment, lists, and code block actions in Configure mode (**NG-722-P18**).
- **Block-insert split at caret** — separator, macros, and images split the active text block at the correct markdown offset, including formatted markdown (**NG-722-P19/P20**).
- **Plain-text block autosize** — split-after and slash/empty plain-text blocks grow to fit all lines on mount (**NG-722-P21**).

## Changed

- **Horizontal separator canonicalization** — standalone `---`, `***`, and `___` lines parse as separator blocks; save emits canonical `---` only (**NG-722-P16**).
- **Wiki text block active surface** — editing keeps the same padded gray surface as preview hover (**NG-722-P17**).
- **Inter-block markdown serialization** — block boundaries preserve blank lines so View/Markdown tab round-trip does not glue blocks (**NG-722-P19**).
- **Insert modals** — table and link modals dismiss on **Escape** via shared `useCancelOnEscape` (**NG-722-P18**).

## Fixed

- Mixed HR markdown forms collapsing to literal dashes in View (**NGB-056**).
- Adjacent wiki blocks glued on one line after Markdown tab save (**NGB-057**).
- Block insert splitting at wrong cursor offset with headings and inline formatting (**NGB-058**).
- Split-after text block textarea stuck at single-row height until save/reopen (**NGB-059**).

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.3.7** and `REACT_APP_VERSION` on the UI service, then run `docker compose pull && docker compose up -d`.
- **No new Prisma migration** — UI and wiki markdown parsing/serialization only.
- Requires **0.3.6** images or a fresh **0.3.7** pull of the full stack.
