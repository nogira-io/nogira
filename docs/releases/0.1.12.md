## Added

- **Plan view polish (NG-603)** — **PlanStatusChip** on activity rows; single **Activity | Timeline** separator; linked horizontal scroll (column header + milestones + grid pan together); child rows stay expanded after panel status edit.
- **Wiki Mermaid (NG-607)** — **Insert Mermaid** modal with preview; **view** renders diagrams as SVG; **edit** uses a `mermaid` code block (WYSIWYG) or raw fence in the Markdown tab; shared `rich-document/mermaid/` pipeline.
- **Rich activity description (NG-610)** — Rich edit + view on activity detail panel and single-page browse; activity-scoped attachment URLs on save; legacy plain-text descriptions remain readable. Image resize/crop overlay deferred to **NGF-050**.
- **Portfolio ↔ Development visibility (NG-606)** — Scheme-driven cross-workspace `parentId` (portfolio leaf → development root); portfolio member **GUEST** sync on children (`syncedFromPortfolioId`); **`GET /api/workspaces/parent-candidates`** and **`GET /api/workspaces/:id/child-workspaces`**; federated **activities** and **plan** rollup (`scope=portfolioRollup`); **Child Workspaces** sidebar panel on portfolio workspaces (`/workspaces/:id/child-workspaces`); board create gated by workspace type (portfolio: Kanban only; development/custom: Kanban + Scrum). Migration `20260601120000_ng606_portfolio_membership_sync`.

## Changed

- **Portfolio activities list** — Tree expand uses rollup children across linked development workspaces; drag-and-drop supports cross-workspace bridge drops inside the federated tree.
- **Activity detail** — **Linked activities** section for cross-workspace children at portfolio leaf types; **Add child** only when the type level allows in-workspace children.
- **Workspace discovery** — Shared **WorkspacesDiscoveryView** for `/home/workspaces` and portfolio **Child Workspaces**; parent portfolio badge on child workspace cards.
- **Create workspace** — Parent portfolio picker uses server **parent-candidates** policy (admin vs manager rules).

## Fixed

- **Cross-workspace linking** — Epic (portfolio) ↔ Feature (development) parent assignment and reorder-tree inside federated rollup no longer blocked by same-workspace-only validation (**NG-606** Ph8).
- **Portfolio rollup display** — Federated tree on `/activities` and plan view shows development work under portfolio epics without requiring duplicate portfolio-side child types.
- **Wiki Mermaid insert (WYSIWYG)** — Modal insert now writes a valid ` ```mermaid ` fence (not paragraph HTML), so diagrams render after save (**NG-607** Ph1b).

## Known limitations

- **Browse parent picker** — Changing parent on `/workspaces/{devId}/activities/{key}` may not persist; use activity detail panel or modal (**NG-606** Ph8c deferred).

## Upgrade notes

- **Public installer default version:** edit `docker-compose.yml` tags to **0.1.12** on `nogira-core`, `nogira-ui`, and `nogira-notification-worker`; set `REACT_APP_VERSION` to `'0.1.12'`.
- Run `docker compose pull && docker compose up -d`.
- **No manual NoGira SQL** — Prisma `migrate deploy` on core startup applies `20260601120000_ng606_portfolio_membership_sync` (portfolio membership sync column).
- **PostgreSQL** stays on `postgres:14` — do not bump to PG 15+ without a PostgreSQL major-upgrade procedure ([deployment.md](../deployment.md)).
- From **0.1.11:** existing volumes compatible; keep **core**, **UI**, and **notification-worker** on the same semver.
- **Portfolio upgrades:** after deploy, portfolio **MEMBER**/**MANAGER** users receive **GUEST** on existing development children on next membership sync hook (add/remove child or member change recalculates).
