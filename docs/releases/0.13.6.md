# NoGira 0.13.6

**Release date:** 2026-11-23

**Fix / feature:** Ops, BizDev, and Marketing workspace templates with DEVELOPMENT-parity scheme clone, portfolio child create/link, and catalogue + `createWorkspace` MCP (**NGF-045** / **NG-775**). No GIF.

## Added

- Workspace types **OPS**, **BIZ_DEV**, **MARKETING** with DEFAULT type/flow/screen schemes cloned on create (same path as DEVELOPMENT).
- **PARTNER** activity type and **Partner Type** multi-select on BizDev templates.
- Portfolio Child Workspaces: create typed children under a portfolio and link orphan workspaces.
- MCP catalogue tools (list/get/create/update, link/unlink, attach/detach) and thin **`createWorkspace`** over existing product REST; public catalog **61** tools.
- QA: `tests/api/workspace-ops-biz-marketing.spec.ts`; seed authorize via install token (`x-nogira-setup-session`).

## Changed

- Create-workspace UI selector and parent candidates include the three new types; optional portfolio parent.
- Warm bootstrap seeds missing DEFAULT Ops/BizDev/Marketing schemes without rewriting existing clones.

## Fixed

- Concurrent first callers of the system working calendar no longer 500 on unique `instanceKey` (P2002 race).

## Out of scope (unchanged)

- Product versions / archive MCP (deferred). Catalogue editors / graph MCP tools. Sample installer compose stays on **`latest`**.

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`**.
- Promote matching **core + ui + worker + mcp** images together (Prisma enum migration + mcp tools).
