# NoGira 0.0.2

**Release date:** 2025

## Added

- **Activity types** management and default type catalog seeding.
- **Activity statuses** with flow categories and colors.
- **Activity flows** — visual workflow editor, versioning (draft v0 + published versions), publish validation.
- **Activity flow schemes** mapping types to workflows.
- **Field definitions** (system + custom fields), field options, **field schemes**.
- **Screens** and **screen schemes** (type → screen → field scheme context).
- **Settings** surfaces for types, fields, flows, screens, and schemes (system admin configuration).
- Default seeds for flows, schemes, screens, and field layouts (idempotent upsert).

## Changed

- Screens decoupled from field schemes for reuse across schemes.

## Upgrade notes

- Database migrations required on upgrade (automatic on core startup in current installers).
