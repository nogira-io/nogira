# NoGira 0.8.8

**Release date:** 2026-11-07

**Mobile wiki Export to PDF + Prisma pool headroom** — Mobile wiki readers get the same **Export to PDF** action as desktop (overflow `…` next to Edit). Hosted and local stacks raise core Prisma `connection_limit` to **15** and `pool_timeout` to **10** so concurrent challenge/onboarding traffic is less likely to stall on the old pool of 5.

**Tracking:** **NG-745** / **NGF-082** / **NGF-079**, **NGB-095** (pool follow-up). Public installer sample compose stays on **`latest`**. Candidate tag promoted: **`dev-8a89ef3-dirty`**.

## Assets

- No GIF or screenshot required for this patch.

## Added

- Mobile wiki page header `…` menu with **Export to PDF** (same `GET /api/wiki/pages/:id/export/pdf` engine as desktop **NG-722-P14**) (**NG-745**).
- Shared UI helper `downloadWikiPagePdf` used by desktop and mobile export paths.

## Changed

- Handbook / Ansible / QA Prisma pool defaults: core **`connection_limit=15`**, **`pool_timeout=10`** (worker limit remains **2**, timeout **10**).
- `cicd-deploy.sh` / `cicd-release.sh` now pass pool limits from `.env.deploy` into Ansible.

## Fixed

- Mobile wiki had no path to export a page to PDF (**NG-745**).

- UAT promote of the same tag (**DEPLOY SUCCESS** · smoke `uat.api` / `uat.mcp`).
- Product e2e for mobile Export PDF **not** added this slice (operator skip for UAT gate).

## Upgrade notes

- Pin `nogira-core`, `nogira-ui`, `nogira-worker`, and `nogira-mcp` to **0.8.8** together when the Hub tags exist, then `docker compose pull && docker compose up -d` (or keep sample `:latest` if that is your eval setup).
- Public installer `docker-compose.yml` is **not** version-pinned in this release (sample stays on **`latest`**).
- Hosted operators: recreate core/worker after deploy so `DATABASE_URL` query args pick up the new pool caps.
- No manual SQL for NoGira schema migrations (applied on core startup).
- PostgreSQL remains pinned at `postgres:14` — do not change major version without a PostgreSQL migration procedure ([deployment.md](../deployment.md)).
