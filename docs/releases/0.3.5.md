# NoGira 0.3.5

**Release date:** 2026-06-15

**NG-722 activity & board technical fixes** (**NGF-079** / **NG-722-P13**) — assignable-user scoping, Scrum backlog completeness, activities list polish, and partial board rank drag-and-drop improvements.

**Tracking:** **NG-722-P13**, **NGF-079**, **NGB-055** (open — rank DnD persistence).

## Added

- **`ASSIGNABLE_USER`** workspace permission matrix row — scopes assignee picker rosters to owner plus members/managers (and guests only when the Guest column is enabled).
- **`GET /api/workspaces/:id/members/assignable`** — backend roster for assignee pickers across activities, boards, and detail surfaces.

## Changed

- **`/activities`** — silent refresh preserves expanded parent rows after rank or parent changes.
- **`/activities`** — **Priority** is included in the default visible column set (Type, Key, Summary, Reporter, Assignee, Status, Priority, Updated).
- **Scrum backlog** — lists all valid unsprinted workspace activity types (not only features/stories), including sub-tasks when applicable.
- **Kanban / Scrum sprint** — same-column rank drag shows insertion-line affordance and sends `workspaceId` with `reorder-bulk` requests.

## Known issues

- **NGB-055** — activities tree and board same-column rank drag-and-drop may show the drop indicator but order does not always persist after drop/refresh. Tracked separately; not a blocker for closing **NG-722-P13**.

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.3.5** and `REACT_APP_VERSION` on the UI service, then run `docker compose pull && docker compose up -d`.
- **No new Prisma migration** — permission catalog/matrix seed upsert for `ASSIGNABLE_USER` runs on core startup.
- Requires **0.3.4** images or a fresh **0.3.5** pull of the full stack.
