# NoGira 0.0.1

**Release date:** 2025

## Added

- Notification engine foundation (**DomainEvent**, **NotificationJob**, in-process dispatch path).
- Dedicated **notification-worker** process (separate from API server).
- Notification events catalog and recipient resolution primitives.
- System notification policy API and instance-level notification settings storage.
- Email service integration (nodemailer) for transactional delivery.
- SMTP configuration on instance settings (enable, host, credentials, test).

## Changed

- Core image split: API vs **nogira-notification-worker** image (same platform version at release time).

## Upgrade notes

- Worker requires database connectivity and compatible core schema version.
