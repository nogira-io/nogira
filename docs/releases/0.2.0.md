# NoGira 0.2.0

**Release date:** 2026-06-11

**Wiki Navigation & Collaboration** (**NGF-067** / **NG-721**) — organise wiki pages with Change Parent and tree drag-and-drop, persist navigation per user, consume content through a Page Context Sidebar, and author rich blocks with macros (TOC, child pages, activity list, attachments list, callouts) in a three-mode block editor. MCP agents can reparent existing wiki pages safely.

**Tracking:** **NG-721** (P1–P8), **NGF-067**, **NGF-043**, **NGF-062**, **NGF-026** (MCP reparent).

## Added

- **Change Parent** — `… → Change parent` on page header and sidebar tree; **Add Link**-style picker (recents + workspace search); **Wiki Home** as immovable root; cycle validation.
- **Tree drag-and-drop** — reorder siblings (insert line) and reparent under a page (row drop); expand-before-drop into collapsed branches; `canWikiManage` gated.
- **Wiki tree persistence** — expand/collapse per user and workspace via `UserPreference`; `collapsedPageIds` survives refresh; path auto-expands on navigation.
- **Page Context Sidebar** (`PageContextExtension`) — icon strip + panel: **Links** (NGF-062 backlinks), **Attachments**, **Comments** (`COMMENT_WIKI`), **Contents** (TOC), **History** (page events).
- **Wiki macros (view + edit-render)** — `{{toc}}`, `{{child-pages}}`, `{{activity-list}}`, `{{attachments-list}}`, callouts (INFO, WARNING, DECISION, SUCCESS, TIP); **Configure** panel (w-72); sample styling per NoGiraSample-macros.
- **All-block wiki editor (P8)** — TipTap block editor; `/` slash picker; macro registry; image and diagram blocks with JWT-safe display; replace image from block chrome.
- **MCP `changeWikiPageParent`** — `PATCH /api/mcp/wiki/pages/:pageId/parent`; optional `position` → `sortOrder`; preserves children, attachments, comments, history, links, and relations (**NG-721-P2**).
- **Wiki page history** — `WikiPageEvent` table; parent-changed and edit events feed the History sidebar tab.

## Changed

- **Wiki navigation defaults** — sidebar tree opens level-1 by default; roots collapsible after first interaction.
- **Child pages** — discovered via **`{{child-pages}}` macro** (list / cards / gallery); empty macro hidden in view mode.
- **Image set** — core, UI, notification-worker, and **nogira-mcp** pinned to **0.2.0**.

## Fixed

- **Tree expand/collapse fight-back** — preference echo no longer re-expands nodes after manual collapse (**P1-T.1**, **P1-T.2**).
- **DnD insert-line visibility** — brand-coloured reorder indicator between siblings (**P1-DnD.3**).
- **Wiki image blocks** — authenticated attachment URLs render via blob fetch in editor/view (**P8-I.14**).

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.2.0** and `REACT_APP_VERSION` on the UI service, then `docker compose pull && docker compose up -d`.
- Hub must publish **core**, **UI**, **notification-worker**, and **nogira-mcp** at **0.2.0** with the same semver (`cicd-release.sh --version 0.2.0` after dev/uat validation).
- Upgrading from **0.1.19**: applies migrations `20260609120000_wiki_page_comments` and `20260609140000_wiki_page_events` on core startup (Comments tab + History tab).
