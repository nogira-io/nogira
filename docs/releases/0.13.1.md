# NoGira 0.13.1

**Release date:** 2026-11-19

**Fix:** Time tracking UX polish after **0.13.0** (**NGDEV-404-PX6** / **NGF-019**). No GIF.

## Fixed

- **My Time** week calendar: overlapping entries that overflow to `+N` no longer paint the two visible blocks at full-cluster width (e.g. 1/7); visible columns use the visible span (up to 2) so blocks fill available space.
- **My Time** today day badge uses theme primary (`var(--ng-primary)` / `var(--ng-primary-fg)`) instead of hardcoded black (week + month views).
- **Worklogs** **Log Time** control matches **Add child** (`ActionButton` gray + Plus) on desktop and mobile.

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`**.
- Promote matching **core + ui + worker + mcp** images together (UI-only fix in this tag; still keep versions aligned).
