# NoGira 0.7.2

**Release date:** 2026-10-26

**Column values in activity tables** — a field you check in Configure Columns shows the value stored on the activity, on home search and on a workspace Activities page.

**Tracking:** **NGB-065**.

No screenshot.

## Fixed

- Home search and workspace Activities include `columnValues` on each row. A checked field renders that text.
- A single-select shows the option label. A multi-select joins option labels. A user field shows the person’s name. Text, number, toggle, date, and url use the stored value.
- Description, Parent, and the other built-in columns stay on the activity row.
