# NoGira 0.12.3

**Release date:** 2026-11-16

**MCP structured activity search + public tool catalog** (**NGF-079** / **NGDEV-362** P1–P2 / P4–P5). No GIF.

## Added

- MCP `searchActivities` reuses the UI search engine (`runActivitySearchQuery`) with projected fields (`status`, `activityType`, `labels`, `priority`, `assignee`, `customFields`, …) (**NGDEV-362-P1**).
- `getActivitySearchSchema` discovery for searchable keys/operators (fail-closed unsupported scoping) (**NGDEV-362-P1**).
- Priority + custom-field filters and structured label operators (`containsAny` / `containsAll` / `containsNone`) on MCP search (**NGDEV-362-P1**).
- MCP `renameWikiPage` (title/slug only; required `lastKnownVersionNumber`) (**NGDEV-362-P4**).
- Public unauthenticated catalog on the MCP HTTP host: `GET /`, `/mcp.json`, `/tools.json` (37 tools from the live registry) (**NGDEV-362-P5**).
- `npm run catalog:generate` writes `public/mcp.json` + `public/tools.json`; connect guide in `nogira-mcp/docs/public-catalog.md`.

## Changed

- Multi-activity updates stay on single-activity `updateActivityFields` loops (no bulk mutation API) (**NGDEV-362-P2**; bulk phase cancelled).
- Default search projection omits full description unless requested via `fields`.

## Fixed

- MCP search no longer maintains a parallel lean Prisma where-path for filters already supported by UI search.

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`** (do not pin tags in the sample).
- Promote matching **core + ui + worker + mcp** images together (mcp catalog is served by **nogira-mcp**).
- No Prisma migration in this release.
- After upgrade, open `https://<tenant>.mcp.<domain>/` or `/tools.json` to verify the public catalog (no PAT required for catalog routes; `/mcp` still requires a PAT).
