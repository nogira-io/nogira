# NoGira 0.11.4

**Release date:** 2026-11-13

**Rich editors + Wiki caret/tree/context counts** (**NGF-043**, **NGF-046**, **NGF-082**, **NG-768**, **NG-769**, **NG-770**, **NGB-104**). No GIF.

## Added

- Create Activity description uses the activity rich markdown editor on desktop and mobile (images stay disabled until the activity exists).
- Light rich composers for activity comments (desktop + mobile quick-comment sheet) and wiki page comments.
- Eager Wiki context badges for links, comments, and attachments without opening the context rail.

## Fixed

- Activity description **Insert table** used the wrong Toast key (`colCount`); inserts now use `columnCount` so saved tables render as grids instead of vertical `|` lines (**NGB-104**).
- New Wiki page typing no longer leaves the caret one character behind.
- Restored expanded Wiki tree nodes load children immediately.
- Create Activity description scroll chrome and empty Write/Preview placeholder leak in rich comment hosts.

## Changed

- Shared `RichDocumentEditor` focused rehydrate guard and caret-to-end handoff reused by Wiki and activity hosts.

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`** (do not pin tags in the sample).
- Promote matching **core + ui + worker + mcp** images together.
- No new Prisma migrations in this slice.
