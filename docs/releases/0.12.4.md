# NoGira 0.12.4

**Release date:** 2026-11-16

**Desktop board Move parity + Change Status** (**NGF-079** / **NGDEV-372** P1–P6). No GIF.

## Added

- Kanban and Scrum Active Sprint column header **select-all** (checked / unchecked / indeterminate) for visible/loaded cards (**NGDEV-372-P2**).
- Board Actions **Move** opens the shared desktop Move modal (`ActivityMoveModal` / `ActivityMovePanel`) (**NGDEV-372-P3**).
- Activity detail panel **⋯** overflow menu with Move / Clone / Archive (**NGDEV-372-P4**).
- Board Actions **Status** opens a Change Status modal: read-only activity type per group, available transitions below, separators between types, primary **Change status** (**NGDEV-372-P6**).
- E2E: `board-column-select-all-and-move.spec.ts` (**NGDEV-372-P5**).

## Changed

- Move toast names the **target workspace** (cross-workspace) or indicates **within** the current workspace when remapping type/status in place (**Q372.5**).
- Same-workspace Move remaps type/status **in place** (keeps activity key and assignee); cross-workspace Move still re-keys and clears sprint membership (**NGDEV-372** / core `move-to-workspace`).

## Fixed

- Core no longer rejects same-workspace `POST /api/activities/move-to-workspace` with “Target workspace must be different…” — same-workspace type/status remap is allowed.

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`** (do not pin tags in the sample).
- Promote matching **core + ui + worker + mcp** images together (UI Change Status + core same-workspace Move).
- No Prisma migration in this release.
- After upgrade: on a Kanban/Scrum board, select cards → Actions → **Move** / **Status**; multi-type Status shows one section per type with separators.
