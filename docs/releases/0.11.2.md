# NoGira 0.11.2

**Release date:** 2026-11-13

**Portfolio CUSTOM rollup + parent bridge + Activities refresh + mobile comment/board polish** (**NGF-063**, **NGF-082**, **NG-762**, **NG-764**, **NG-765**, **NG-726-P20**, **NGB-102**, **NGB-103**).

## Added

- Portfolio Activities / Plan **rollup** includes **CUSTOM** child workspaces (e.g. ONBOARDING) alongside DEVELOPMENT (**NG-762**).
- Cross-workspace **parent bridge** for CUSTOM scheme-root activities → Portfolio leaf (e.g. ONBOARDING TASK → PMO EPIC), same rules as DEVELOPMENT (**NG-764** / **NGB-102**).
- Mobile **Comment** FAB (primary Create-style control) and shared comment sheet padding; Kanban/Scrum toolbar **RefreshCw**; workspace selector **All spaces** row (**NG-726-P20**).

## Fixed

- After setting a parent on Portfolio Activities, the silent list refresh no longer drops `portfolioRollup` (stale `workspaceType` closure) — child-workspace rows stay visible (**NG-765** / **NGB-103**).
- CUSTOM activities can find and link Portfolio leaf parents in Parent search (**NG-764** / **NGB-102**).

## Changed

- Activity / wiki comment composers open the shared mobile quick-comment sheet; desktop comment sections align padding with sheet chrome (**NG-726-P20**).

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`** (do not pin tags in the sample).
- Promote matching **core + ui + worker + mcp** images together.
- No new Prisma migrations in this slice.
- Membership same-role fan-out (**NG-763**) remains draft / not in this release.
