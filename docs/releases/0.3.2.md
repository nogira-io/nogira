# NoGira 0.3.2

**Release date:** 2026-06-14

**NG-723** — workspace **`/plan`** archive filter (**NGF-044** / **NGF-017**): plan API and portfolio rollup now return only active (non-archived) activities, matching activities list, search, and boards.

**Tracking:** **NG-723**, **NGF-044**, **NGF-017**.

## Fixed

- **Plan view:** **`GET /api/workspaces/:id/plan`** no longer includes archived activities; KPI counts and the Gantt tree reflect active work only.
- **Portfolio plan rollup:** child-workspace activities in portfolio **`/plan`** exclude archived rows (same **`archivedAt IS NULL`** contract as **NG-715**).

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.3.2** and `REACT_APP_VERSION` on the UI service, then `docker compose pull && docker compose up -d`.
- **No new Prisma migration** — backend query filter only.
- Requires **0.3.1** images or a fresh **0.3.2** pull of core (UI tag bump keeps installer alignment; no UI code change in this slice).
