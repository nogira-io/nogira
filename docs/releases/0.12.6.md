# NoGira 0.12.6

**Release date:** 2026-11-16

**Board multi-select Move** (**NGF-079** / **NGDEV-372-P8**). No GIF.

## Added

- Board Actions **Move** works for **one or more** selected cards; all selected activities move/remap to the **same** destination workspace, activity type, and status (**NGDEV-372-P8**).

## Changed

- Move is no longer limited to a single selected card on Kanban / Scrum Active Sprint toolbars.
- Modal continues to use shared `ActivityMovePanel` (hint when N>1: moving N activities to the same workspace, type, and status).

## Fixed

- Multi-select Move was incorrectly disabled with “Select exactly one activity to move”.

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`**.
- Promote matching **core + ui + worker + mcp** images together (UI-only behavior change in this release).
- No Prisma migration in this release.
- After upgrade: on a board, select 2+ cards → Actions → Move → choose one workspace/type/status → confirm all update.
