# NoGira 0.7.1

**Release date:** 2026-10-26

**Activity field values and column pickers** — a single-select stored on an activity is returned to the ticket screen. A field scheme can take a new custom field. Configure Columns lists the fields that belong on that screen.

**Tracking:** **NGB-065**.

No screenshot.

## Fixed

- `GET /api/activities/:key` returns a single-select from `optionId`, a user field from `userId`, and a date-time from `dateTimeValue`. Hands-on Interest and Attendee Role show the stored option. Hands-on Session Preferences was already returned.
- Saving a field scheme keeps the fields you send and adds any system field the scheme did not have yet. Adding SELECTOR no longer fails with “All system fields must be included in the scheme”. A real save failure uses the error modal.
- Workspace Activities → Configure Columns lists that workspace’s Activity Field Scheme, plus Type, Key, Status, Updated, Last activity, and Completed. Checked columns stay at the top. A search box filters the rest.
- Home search → Configure Columns lists every field definition, with the same search and checked-first order. It is not limited to system fields.
- Description and Parent render in those tables from the activity row.
