# NoGira 0.13.5

**Release date:** 2026-11-21

**Fix:** MCP time-tracking tools over existing product REST (**NGF-019** / **NGDEV-485**). Agents can log and inspect authorized worklogs and My Time without new core APIs, schema, UI, or timers. No GIF.

## Added

- **MCP time tools** (`nogira-mcp`): `listActivityWorklogs`, `logActivityTime`, `updateActivityWorklog`, `deleteActivityWorklog`, `bulkLogActivityTime`, `getMyTime`, `getActivityTimeSummary`, `getActivityPendingTimeSuggestions` (read-only), `getWorkspaceEstimationDefaults`, `getSystemWorkingCalendar` (admin-gated REST).
- Public catalog regenerated (**50** tools). Docs table + samples in [`docs/mcp.md`](../mcp.md).
- QA: `tests/api/mcp-time-tracking.spec.ts` — member/manager PAT authz against product worklog/my-time paths.

## Changed

- MCP hard limits: **≤31** days per `logActivityTime`; **≤50** items per `bulkLogActivityTime` (bounded concurrency, per-item results, no blind create retry).
- Personal day/week/month beyond REST `dayTotals` / `periodTotalMinutes` stays **client aggregation** of `getMyTime` (no dedicated report endpoint).

## Fixed

- N/A (capability add on existing time REST).

## Out of scope (unchanged)

- No new REST `/api/mcp/*` time facades, DB migrations, UI, permissions model, team-time reports, or session confirm / timer start-stop tools.

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`**.
- Promote matching **core + ui + worker + mcp** images together (mcp image carries the new tools).
- Smoke: with a PAT, Cursor/Claude can `logActivityTime` then `getMyTime` / `getActivityTimeSummary` on an activity the user can edit; catalog has no confirm/timer tools.
