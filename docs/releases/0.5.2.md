# NoGira 0.5.2

**Release date:** 2026-10-23

**Notification queue controls** (**NGB-062**, **NG-729**) — `/settings/notifications` can clear mail that was already sent or failed, and mail that is still waiting. The jobs table pages 50 rows at a time.

**Tracking:** **NGB-062**, **NG-729**, **NGF-004**.

## Fixed

- The jobs table shows 50 jobs per page, with page numbers. A checkbox on the left deletes the selected jobs.
- Clear sent and failed removes every sent job and every failed job, on every page.
- Clear unsent removes every pending job and every pending domain event that has not become a job yet. In-progress jobs stay. Events that were already dispatched stay.
- The page counts events that are still waiting and are not rows in the table.

## Upgrade notes

- Dev and UAT stay on the last deployed tag until you promote this candidate. The public installer tags in `docker-compose.yml` stay on the last published semver until `cicd-release.sh`.
- No Prisma migration. Core and the product UI both change. UAT still has the pending events from 2026-10-23 until an administrator uses Clear unsent there.
