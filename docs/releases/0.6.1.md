# NoGira 0.6.1

**Release date:** 2026-10-24

**Activity create permission** — a Guest, and a signed-in user who is not a member of the workspace, can no longer create an activity. The API reads the workspace permission matrix.

**Tracking:** **NGB-061**, **NG-730**, **NGF-027**.

No screenshot.

## Fixed

- `POST /api/activities` checks `CREATE_ACTIVITIES` before it inserts a row.
- `POST /api/activities/:id/children` checks the same permission on the parent activity’s workspace.
- A denial returns **403** and does not store the activity.
- Owner and Manager creates stay allowed when that workspace’s matrix has the permission on.
- The allow or deny comes from `WorkspaceRolePermission`. It is not a hardcoded Guest rule.
