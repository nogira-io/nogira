# NoGira 0.1.16

**Release date:** 2026-06-04

**Manage Users display names** (**NG-713.4**) — admins see and edit user **full name** on **Manage Users** and in **Edit User**. Shipped in **nogira-core** and **nogira-ui** at **0.1.16** (no extra Compose service).

**Tracking:** **NG-713.4**, **NGF-051**.

## Added

- **Manage Users** — **Full name** column before **Email**; anonymized rows show **Deleted User** in the name column and **—** in email.
- **Edit User** — **Full name** field (saved via `PATCH /api/system/users/:id` with optional **`fullName`**).

## Changed

- **Image set** — core, UI, notification-worker, and **nogira-mcp** pinned to **0.1.16**.

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.1.16** and `REACT_APP_VERSION` on the UI service, then `docker compose pull && docker compose up -d`.
- Hub must publish **core**, **UI**, **notification-worker**, and **nogira-mcp** at **0.1.16** with the same semver (`cicd-release.sh --version 0.1.16` after dev/uat validation).
- Upgrading from **0.1.15**: bump all four runtime images together; no new schema migrations for this release.
