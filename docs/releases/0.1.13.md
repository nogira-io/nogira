# NoGira 0.1.13

**Release date:** 2026-06-02

**NoGira MCP Integration Platform** (**NGF-026**) for the public evaluation installer: MCP server in Compose, platform images at **0.1.13**, plus user docs for Cursor and PAT auth. Platform images at this tag also include the **Event Challenge Engine** (**NGF-048**) shipped with core/UI in the same semver.

## Added

- **`nogira-mcp` service** in `docker-compose.yml` — Streamable HTTP on `http://localhost:3100/mcp` (`ng-mcp` container).
- **Core MCP adapter flags** on `nogira-core` — `MCP_CORE_ROUTES_ENABLED`, `NOGIRA_MCP_WRITE_ENABLED`, `NOGIRA_MCP_ACTIVITY_WRITE_ENABLED` (defaults on for evaluation).
- **MCP public guide** — `docs/mcp.md`: what MCP is, URLs, auth model (PAT passthrough), MVP1 tool list, and Cursor setup (Streamable HTTP). See [screenshots above](#screenshots).
- **Event Challenge Engine** (**NGF-048**) — admin challenge list, join tokens, presenter/attendee flows, and profile-menu join-by-code (platform UI/API; not a separate Compose service).

## Changed

- **Image set** — all four runtime images (`nogira-core`, `nogira-ui`, `nogira-notification-worker`, `nogira-mcp`) pinned to **0.1.13** (same semver required).
- **Deployment docs** — `docs/deployment.md`: MCP image, port **3100**, endpoint URLs, and links to the MCP guide.
- **Quick start** — `docs/quick-start.md`: MCP service, port, and link to `mcp.md`.

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.1.13** and `REACT_APP_VERSION` on the UI service, then `docker compose pull && docker compose up -d`.
- Hub must publish `nogira/nogira-mcp:0.1.13` with core, UI, and notification-worker at the same tag (promote via `nogira-handbook/scripts/cicd-release.sh --version 0.1.13` after dev/uat validation).
- Create a **Personal Access Token** in the UI (Account) before connecting Cursor; see [mcp.md](../mcp.md).
- Upgrading from **0.1.12**: move core, UI, and worker together and add the new `nogira-mcp` service at **0.1.13**.
