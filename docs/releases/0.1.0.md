# NoGira 0.1.0

**Release date:** 2026-05-16

## Added

- **Self-serve Docker setup** — `/setup` wizard, persisted instance config, `migrate deploy` on container start (**NG-077**).
- **Home dashboard** (`/home`) — summary, recent activity, quick actions.
- **My Work** personal view with persisted UI preferences.
- Workspace **activities list** and activity detail foundations.
- Registration, login, password reset, and access-request flows.
- Hosted **demo** environment packaging (formal demo release track).

## Changed

- Login gated until instance **setupCompleted**.
- CI/CD release flow: candidate Hub tag → semver retag → demo deploy → `vX.Y.Z` git tag.

## Fixed

- Prisma client lifecycle during setup (shared client in auth paths).

## Upgrade notes

- First semver used for hosted demo promotion (`cicd-release.sh`).
- PostgreSQL bundled; NoGira migrations automatic on core startup.
