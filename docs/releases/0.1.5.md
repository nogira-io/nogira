## Added

- **Wiki** per workspace — page tree, markdown editor (Toast UI), view/edit modes.
- Wiki attachments (upload, list, download, delete) with image preview pipeline.
- Workspace wiki search (`#tag` and text search).
- **Public installer repository** (`nogira-io/nogira`) — single-node Docker Compose, pinned [Docker Hub](https://hub.docker.com/u/nogira) images, setup wizard path.
- Rich document image layout (shared editor building blocks for wiki images).

## Changed

- Wiki attachment storage keys aligned to flat `wiki/attachments/…` topology (legacy keys still readable).
- Simplified **evaluation compose**: PostgreSQL 14 + core + notification-worker + UI (no pgAdmin in public installer).

## Fixed

- Wiki optimistic concurrency and soft-delete subtree behaviour hardened.
- Notification worker startup when instance not yet initialized (waits for setup).

## Upgrade notes

- **Public installer default version:** edit `docker-compose.yml` tags to `0.1.5` on `nogira-core`, `nogira-ui`, and `nogira-notification-worker`.
- Run `docker compose pull && docker compose up -d`.
- **No manual NoGira SQL** — Prisma `migrate deploy` runs on core startup.
- **PostgreSQL** stays on `postgres:14` — do not bump to PG 15+ without a PostgreSQL major-upgrade procedure ([deployment.md](../deployment.md)).
- From **0.1.4:** existing volumes compatible; mixed image versions unsupported.
