# NoGira 0.1.11

**Release date:** 2026-05-31

## Added

- **Global search (Postgres FTS)** — full-text + trigram search on activity and wiki excerpt columns; expression GIN indexes; **Reindex search documents** on **System settings** (SYSTEM_ADMIN). Migration `20260531120000_ng605_p1_fts_search`.
- **Top-bar quick find** — grouped activity + wiki hits in the toolbar dropdown; **Cmd/Ctrl+K** shortcut; **`GET /api/global-search`**.
- **Search across surfaces** — FTS-backed search on **`/home/search`**, workspace activity lists, Kanban/Scrum boards (`search-match-ids`), sprint backlog, and wiki sidebar (snippets + relevance sort when `q≥2`).
- **My Work discovery** — **View all** and quick-filter KPI shortcuts open **`/home/search?…`** from Customize My Work preferences; **`GET /api/my-work/quick-filter-counts`**; six system default saved filters on bootstrap.
- **First-run onboarding wizard** — **`welcome-v1`** (Profile → Background → Learn → Tell us → Get started); **`/api/onboarding/wizards/:wizardKey`**; migration `20260530120000_ng608_user_onboarding_wizard`.
- **Onboarding catalog v5** — **1 parent + 9 `NG609_*` missions**; persona Learn tracks; Explore-only cap (3 keys); legacy v3 catalog never provisioned.

## Changed

- **Search relevance** — activity key ranked **A+**; FTS config **`simple`**; wiki hits exclude soft-deleted pages.
- **My Work / Search table** — optional columns (Due date, Start Date, Completed, Labels, Priority); horizontal scroll; date column sort; activity key color **#111827**; calendar due presets in instance timezone.
- **Scrum board parity** — column accent colors persist after DnD; optimistic card moves (no full-board flash); shareable **`?tab=backlog|active-sprint|metrics`**; toolbar filters on backlog and active sprint (search + assignee server-side; reporter/type/status client-side); workspace-scoped Type/Status catalogs on boards and Activities list.
- **Onboarding provision** — parent title **`Welcome {displayName} to NoGira!`**; wizard tasks step lists provision API titles.

## Fixed

- **Global top search** — toolbar field was non-functional; now wired to FTS engines end-to-end (**NG-605**).
- **Board/wiki search loops** — **Maximum update depth exceeded** on Kanban, Scrum active sprint, and wiki sidebar when search idle (**NGB-048**; stable debounced search hook).
- **Scrum column colors** — accent colors no longer break after drag-and-drop (**NG-604** / **NGB-028**).

## Upgrade notes

- **Public installer default version:** edit `docker-compose.yml` tags to **0.1.11** on `nogira-core`, `nogira-ui`, and `nogira-notification-worker`; set `REACT_APP_VERSION` to `'0.1.11'`.
- Run `docker compose pull && docker compose up -d`.
- **No manual NoGira SQL** — Prisma `migrate deploy` on core startup applies onboarding wizard + FTS excerpt/index migrations.
- **PostgreSQL** stays on `postgres:14` — do not bump to PG 15+ without a PostgreSQL major-upgrade procedure ([deployment.md](../deployment.md)).
- From **0.1.10:** existing volumes compatible; keep **core**, **UI**, and **notification-worker** on the same semver.
- **After upgrade:** SYSTEM_ADMIN may run **Reindex search documents** once on **System settings** if upgrading from a DB that predates FTS excerpt backfill (optional; excerpts populate on activity/wiki writes).
