# NoGira 0.3.1

**Release date:** 2026-06-14

**NG-722 UI follow-on** (**NGF-079** companion polish) — product-shell improvements shipped alongside the MCP activity operations foundation: persisted navigation/wiki tree state, create-activity stay-in-context, semantic toast standardization, and wiki tree toast feedback for archive and reparent flows.

**Tracking:** **NG-722-P4**, **NG-722-P5**, **NG-722-P6**, **NG-722-P7**, **NGF-079**.

## Changed

- **UI preferences:** left navigation collapse and wiki tree shell collapse persist across refresh (per workspace for the wiki tree).
- **Create Activity modal:** success no longer redirects away from the current page; the success toast deeplink still opens the new activity.
- **Toast system:** one generic semantic toast layout for green (create/save), blue (change/info), yellow (warning/archive), and red (system error), with optional title, message, icon, and reporter.

## Fixed

- **Created-activity toast:** shows activity key and summary in the compact left-rail layout with extended visibility duration.
- **Wiki tree drag/drop:** collapsed-branch rejection (`Expand the branch before moving a page into it.`) and related rejections use warning toasts instead of browser alerts.
- **Wiki page archive:** successful archive shows a yellow archive toast.
- **Wiki page parent change:** successful reparent (drag/drop or Change parent modal) shows a blue info toast.

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.3.1** and `REACT_APP_VERSION` on the UI service, then `docker compose pull && docker compose up -d`.
- **No new Prisma migration** — UI-only follow-on to **0.3.0**.
- Requires **0.3.0** MCP activity operations foundation images (or same **0.3.1** build that includes both slices).
