# NoGira 0.8.2

**Release date:** 2026-10-29

**Settings UX consistency, wiki navigation performance, workspace purge clarity, and CLC load tooling** — No new product surface. This patch ships bug-fix and operator-tooling work from **NG-735**–**NG-738**, **NG-734-P15**, and **NG-734-P17** (**NGB-072**–**087**).

**Tracking:** **NG-735**, **NG-736**, **NG-737**, **NG-738**, **NG-734-P15**, **NG-734-P17**, **NGB-072**–**087**. **NGB-071** / **NG-734-P16** remain open (demo worker credential parity).

## Assets

- No GIF or screenshot required for this bugfix / tooling patch.

## Changed

- **Settings list chrome** — Shared description, search-in-toolbar, checkboxes, pagination, and Delete Actions pattern (Activity Types reference) across activity catalog pages, Manage Users/Workspaces, Forms, Access Requests, and Challenges; gray **SegmentedTabs** with counts where multi-status filters apply.
- **Flow editor** — Settings layout main padding removed so the canvas is full-bleed.
- **Home workspaces** — Wiki and whiteboard counters on discovery cards.
- **Wiki tree** — Lazy branch loading (`parentId` / cursor) plus ancestors API and client navigation cache; DnD no longer forces a full-tree refresh.
- **Workspace purge** — Preview and progress include wiki pages and whiteboards.
- **Performance CLC** — Configurable realistic-user load scripts and modes under `nogira-testing/performance` (NG-734-P15).

## Fixed

- **NGB-072** — Purge modal missing wiki / whiteboard counts and steps.
- **NGB-073** — Settings workspaces name not linked to workspace settings.
- **NGB-074** — Wiki DnD refreshed the entire tree.
- **NGB-075** — Home workspaces missing wiki / whiteboard counters.
- **NGB-076** — Manage Users bulk select and account readonly path.
- **NGB-077** / **NGB-078** — Settings tables missing bulk Actions and pagination.
- **NGB-079**–**NGB-087** — Filter tabs / settings list layout parity (SegmentedTabs, Forms, Access Requests, Challenges, Activity Types and catalog pages, flow editor padding).

## Upgrade notes

- Pin `nogira-core`, `nogira-ui`, `nogira-worker`, and `nogira-mcp` to **0.8.2** together when the Hub tags exist, then `docker compose pull && docker compose up -d`.
- No manual SQL for NoGira schema migrations (applied on core startup).
- PostgreSQL remains pinned at `postgres:14` — do not change major version without a PostgreSQL migration procedure ([deployment.md](../deployment.md)).
