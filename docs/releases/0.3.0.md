# NoGira 0.3.0

**Release date:** 2026-06-14

**MCP activity operations foundation** (**NGF-079** / **NG-722**) — AI clients can now perform safe day-to-day activity operations over MCP without relying on unsafe raw patches, including workspace context lookup, hierarchy-safe create/move, workflow-safe transitions, comments, links, archive/restore, and idempotent external-create metadata for activities and wiki pages.

**Tracking:** **NG-722**, **NGF-079**.

## Added

- **MCP activity tools:** `listWorkspaces`, `getWorkspaceSummary`, `getWorkspaceHierarchySchema`, `getActivityChildren`, `createActivity`, `updateActivityDescription`, `updateActivityFields`, `changeActivityParent`, `listActivityTransitions`, `transitionActivity`, `addActivityComment`, `listActivityComments`, `getLastActivityComment`, `addWikiComment`, `listWikiComments`, `getLastWikiComment`, `linkActivityToActivity`, `linkActivityToWikiPage`, `listActivityLinks`, `unlinkActivityRelation`, `archiveActivity`, `restoreActivity`.
- **Core MCP activity routes:** `/api/mcp/workspaces`, `/api/mcp/activities/*`, and wiki comment/link/archive helpers with PAT-owner permission enforcement and compact responses.
- **Idempotent external-create metadata:** `Activity.externalSource` / `externalRequestId` plus `WikiPage.externalSource` / `externalRequestId`, each backed by partial unique indexes for duplicate-safe MCP create flows.

## Changed

- **Safe mutation model:** raw status and parent patching stay out of the MCP AI surface; workflow transitions, parent moves, description edits, and safe field updates now use explicit wrappers.
- **Link contracts:** activity link listing exposes explicit direction and rejects duplicate source/target/relation triplets.
- **Archive visibility:** archived activities stay hidden by default unless restored through explicit tooling.

## Upgrade notes

- Apply the new Prisma migrations: `20260614120000_ngf079_activity_external_metadata` and `20260614130000_ngf079_wiki_page_external_metadata`.
- After image publication, bump all four `nogira/nogira-*` tags in `docker-compose.yml` to **0.3.0** and update `REACT_APP_VERSION` on the UI service, then `docker compose pull && docker compose up -d`.
- MCP clients should prefer the new safe activity tools instead of generic patch-style workflows.
