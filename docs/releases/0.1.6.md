# NoGira 0.1.6

**Release date:** 2026-05-27

## Screenshots

![Activity detail, edition, and workflow](../assets/nogira-activity.gif)

*Unified activity experience: edit summary and description, properties rail (status, priority, assignee), child activities, and **View Flow** for workflow transitions.*

## Added

- **Unified activity detail** — the same layout and controls in the right-hand panel (boards, lists, plan) and on the full activity page.
- **Properties rail** — assignee, reporter, parent, priority, and labels grouped in one place instead of scattered across the form.
- **Planning dates** — start date and due date save to the activity record and stay in sync with the workspace plan timeline (no duplicate date controls).
- **Priority scheme** — priorities are a core activity property with their own options (name, color, sort weight), not a generic single-select field list.
- **System priority defaults** — administrators configure default priority levels under **Settings → Activity Fields → Default**.
- **Workspace priority defaults** — workspace managers can inherit system defaults, customize a workspace-specific set, or reset to system defaults (**Workspace settings → Defaults**).
- **Priority option editor** — manage name, color, and weight; table preview shows color swatch and label only.
- **Remap on remove** — when deleting a priority level still used by activities, choose a replacement before saving.
- **Default priority on create** — new activities receive the scheme’s default level (Medium in the stock seed).

## Changed

- **Priority in edition** — colored swatch selector in the properties rail; values persist on the activity, not only as custom field values.
- **Edition form cleanup** — summary, assignee, reporter, parent, labels, and priority removed from the lower “additional fields” block when already shown in the rail.
- **Rail section order** — Properties, system dates, planning dates, labels, then additional custom fields.
- **Stock screens** — priority marked required on default program, portfolio, and project management screens (aligned with other workspace templates).
- **Sorting** — lists and pickers order priorities by weight (highest first), then name.

## Fixed

- **Planning dates** — editing start or due date in activity detail no longer writes only to custom field storage while the plan view reads empty native dates.
- **Stale detail data** — panel saves refresh host surfaces more reliably after edits (with activity type changes from the prior release).

## Upgrade notes

- **Public installer default version:** edit `docker-compose.yml` tags to `0.1.6` on `nogira-core`, `nogira-ui`, and `nogira-notification-worker`.
- Run `docker compose pull && docker compose up -d`.
- **No manual NoGira SQL** — Prisma `migrate deploy` runs on core startup (includes priority scheme migrations).
- **PostgreSQL** stays on `postgres:14` — do not bump to PG 15+ without a PostgreSQL major-upgrade procedure ([deployment.md](../deployment.md)).
- From **0.1.5:** existing volumes compatible; mixed image versions unsupported.
