# NoGira 0.10.4

**Release date:** 2026-11-12

**Mobile wiki feed polish + workspace key rewrite / CUSTOM parent attach** (**NGF-082**, **NGF-063**, **NG-726-P18–P19**, **NG-761**).

## Added

- Mobile wiki feed **RefreshCw** sync and **pull-to-refresh**, plus swipe actions **Edit / Comment / Move / Clone / Archive** (**NG-726-P19**).
- `POST /api/wiki/pages/:id/move` — move a wiki page (and descendants) to a parent in the same or another workspace (**NG-726-P19**).
- Workspace **key change** rewrites existing activity keys (`OLD-n` → `NEW-n`) with a progress modal; **CUSTOM** workspaces can attach under **PORTFOLIO** or **PROGRAM** when activity type schemes do not overlap (**NG-761**).

## Changed

- Mobile wiki feed sort uses **SegmentedTabs** (Last Updated / Created) with count only on the active tab (**NG-726-P18**).
- Wiki **Move** sheet matches activity Move chrome: **ActionButton** Back + Move, padded card layout, searchable parent page picker that expands for results (**NG-726-P19**).
- Mobile **Comment** sheet (activity + wiki) uses **ActionButton** Cancel + primary **Comment** (**NG-726-P19**).

## Fixed

- Changing a workspace key no longer leaves stale activity key prefixes (**NG-761**).
- CUSTOM workspace edit/create can select a parent program/portfolio when types do not conflict (**NG-761**).

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`** (do not pin tags in the sample).
- Promote matching **core + ui + worker + mcp** images together.
- No manual SQL — no new Prisma migrations in this slice.
