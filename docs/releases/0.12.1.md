# NoGira 0.12.1

**Release date:** 2026-11-14

**Wiki clipboard + code-block polish** (**NGF-100**, **NG-772-P8A**, **NG-772-P8B**, **NG-772-P10**). No GIF.

## Added

- External smart paste: screenshots/images upload as figures; Excel/Sheets HTML or TSV become Wiki table blocks; wiki image copy/paste rehydrates attachments (**NG-772-P8A**).
- Internal block clipboard: Ctrl/Cmd+C on a focused block, Duplicate chrome, and floating **Copy** beside settings/delete on text, macros, tables, images, code, diagrams, and separators; Ctrl/Cmd+V inserts a deep clone with new ids (**NG-772-P8B**).
- Code blocks: shared dark pane in View/Edit/mobile, editable source on second edit, auto-grow height, floating delete (**NG-772-P10**).

## Fixed

- Trailing empty text after image/table/macro so typing can continue; no dead empty row after image insert.
- Excel paste preferred over clipboard bitmap when a `<table>` is present.
- Nested multi-column layouts can insert code blocks (`insertCodeBlock`).

## Changed

- Paste MIME order: internal wiki blocks → wiki image → HTML/TSV table → image file → rich/plain (P8A sanitizer).

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`** (do not pin tags in the sample).
- Promote matching **core + ui + worker + mcp** images together.
- No new Prisma migrations in this slice.
