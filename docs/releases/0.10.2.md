# NoGira 0.10.2

**Release date:** 2026-11-11

**Wiki Export PDF progress modal** (**NGF-079**, **NGF-082**, **NG-758**) — Desktop and mobile **Export to PDF** open a modal with spinner while the PDF generates, then a **Download** button when ready (Confluence-like). Fixes flaky auto-download / long silent waits. No GIF.

**Tracking:** **NG-758**, **NGF-079**, **NGF-082**, DELIVERY-276.

## Fixed

- Wiki Export to PDF no longer auto-downloads after a silent wait — modal shows `NgSpinner` while generating, then **Download** (desktop `WikiPageEditor` + mobile `MobileWikiPage`) (**NG-758**).
- Download is user-gesture driven after the blob is ready (better browser download behavior).
