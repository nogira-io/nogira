# NoGira 0.12.7

**Release date:** 2026-11-17

**Organisation appearance on pre-auth and onboarding** (**NGF-093** / **NGDEV-369** P1–P5). No GIF.

## Added

- Public **`GET /api/system/settings/appearance/public`** — unauthenticated org appearance (appearance fields only; short cache) so login/register/forgot-password pick up instance branding without a token (**NGDEV-369-P1**).
- UI boot applies public appearance before auth routes render (`bootPublicAppearance` + ThemeProvider).
- QA: `tests/api/appearance-public.spec.ts` and `tests/e2e/appearance-preauth-branding.spec.ts` (whitelist + Custom primary on `/login`).

## Changed

- Login / registration / password recovery CTAs and auth shell consume **`--ng-primary`** / shell tokens from org Settings appearance (not hardcoded greens).
- Auth right-panel eyebrow, feature icons, translucent icon chips, and decorative rings use **Primary button** colour (`color-mix` tints) (**NGDEV-369-P5**).
- Onboarding wizard theme / left panel / footer use shell + primary tokens (**NGDEV-369-P2**).
- Configure Workspace wizard next/back/completion and **Deleting workspace** Close use primary tokens (**NGDEV-369-P3**).
- NGF-093 product scope amended: org appearance also brands pre-auth + onboarding (token-only; no layout redesign).

## Fixed

- Pre-auth screens no longer ignore Custom org primary (previously forced LIGHT / hardcoded green accents on the aside).

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`**.
- Promote matching **core + ui + worker + mcp** images together (new public appearance route + UI tokens).
- No Prisma migration in this release.
- After upgrade: set System Settings → Appearance → Custom primary → open `/login` logged out and confirm CTA + aside accents match.
