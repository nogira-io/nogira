# NoGira 0.13.9

**Release date:** 2026-11-25

**Fix:** Activities roots / expand performance — workspace-scoped, page-bounded child presence (no whole-table child aggregate). No GIF.

## Added

- Activity list indexes for roots sort and expand: `(workspaceId, createdAt, id)`, `(workspaceId, parentId, archivedAt)`, `(parentId)`.

## Changed

- `GET /api/workspaces/:id/activities?listMode=roots` and expand children: `treeHasChildren` from a page-bounded, **same-workspace** presence query instead of Prisma global `_count.children`.
- Root membership unchanged (`parentId` null or parent in another workspace).

## Fixed

- Sub-workspace Activities list no longer drives a system-wide child-count aggregate over the entire `Activity` table (Option A Phase 1).

## Out of scope (unchanged)

- Sample installer compose stays on **`latest`**.
- Portfolio rollup full-materialize rewrite and keyset pagination (later phases).

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`**.
- Promote matching **core + ui + worker + mcp** images together (migration applies on core startup).
- Smoke: open a child workspace Activities roots list and expand chevrons; indicators still correct for same-workspace children.
