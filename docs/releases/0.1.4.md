# NoGira 0.1.4

**Release date:** 2026-05-21

## Screenshots

![Scrum board](../assets/nogira-board-scrum.gif)

*Scrum implementation: backlog, active sprint columns, sprint ceremonies, filters, and delivery-oriented board layout.*

## Added

- **Scrum board** — backlog, active sprint, sprint ceremonies, sprint metrics.
- Sprint CRUD, membership, complete/rollover, and retrospective cards.
- Server-side sprint metrics and notification emitters for sprint lifecycle.
- Backlog incremental pagination (“See more”) for large backlogs.

## Changed

- Board configuration extended for Scrum-specific views and filters.
- Notification worker remains on same platform semver as core and UI.

## Fixed

- Sprint metrics history, unit toggle, and board layout polish (multiple board UX fixes).

## Upgrade notes

- Requires **0.1.4** on all three runtime images together.
- Existing Kanban boards unchanged; Scrum is an additional board type where configured.
