# NoGira 0.12.5

**Release date:** 2026-11-16

**MCP activity move + Change Status modal grow** (**NGF-079** / **NGDEV-373** P1–P4 / **NGDEV-372-P7**). No GIF.

## Added

- MCP `listMoveTargetWorkspaces`, `listMoveDestinationStatuses`, and `moveActivitiesToWorkspace` (shared `activityTypeKey` + `statusKey` for one or many activity ids) wrapping the existing move domain (**NGDEV-373**).
- Core MCP routes: `GET /api/mcp/activities/move-targets`, `GET /api/mcp/workspaces/:id/move-destination-statuses`, `POST /api/mcp/activities/move-to-workspace`.
- Public MCP catalog now lists **40** tools (includes the three move tools).

## Changed

- Board **Change status** modal uses an inline status menu (~6 rows) and grows when the picker opens so options are not clipped (**NGDEV-372-P7**).
- In-workspace status-only changes remain on `listActivityTransitions` / `transitionActivity` (documented in move tool descriptions).

## Fixed

- Change Status modal no longer clips the status option list behind `overflowY: auto`.

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`** (do not pin tags in the sample).
- Promote matching **core + ui + worker + mcp** images together (new MCP move tools are served by **nogira-mcp** + **nogira-core**).
- No Prisma migration in this release.
- After upgrade: open `https://<tenant>.mcp.<domain>/tools.json` and confirm `moveActivitiesToWorkspace`; on boards, Actions → Status → open Status and confirm the list is fully visible.
