# NoGira 0.11.3

**Release date:** 2026-11-13

**Access membership fan-out, catalogue QA auth harden, release automation** (**NGF-063**, **NGF-045**, **NG-763**, **NG-766** / **NG-766-P1**, handbook release flag).

## Added

- Workspace **Access** add/remove can optionally apply the **same role** across all ACTIVE direct sub-workspaces (opt-in modals + `childWorkspaceCount`) (**NG-763**).
- Catalogue e2e login waits for a durable session token before navigating protected routes (**NG-766-P1**).
- `cicd-release.sh --non-interactive` skips only the demo **YES** confirmation for trusted automation (other safeguards remain).

## Fixed

- Anonymous `/api/auth/me/preferences` and appearance **401** on the login page no longer clears a freshly issued post-login token (**NG-766-P1**).
- Preferences sync re-initializes when the session token appears after login (**NG-766-P1**).

## Changed

- Silent PORTFOLIO→GUEST-on-DEVELOPMENT membership fan-out replaced by explicit same-role fan-out to all direct children when the operator opts in (**NG-763**).
- Catalogue UI e2e keeps list + create; **edit / version / link** journey deferred for a later selector pass (**NG-766**).
- Public README documents Products & Services catalogue and My Work sections (shared GIF asset notes).

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`** (do not pin tags in the sample).
- Promote matching **core + ui + worker + mcp** images together.
- No new Prisma migrations in this slice.
- Planning-workspace identity rename docs (**NG-767**) are documentation-only and do not change runtime APIs.
