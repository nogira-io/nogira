# NoGira 0.8.12

**Release date:** 2026-11-09

**Home Search columns + export** — Saved filters restore Configure columns with the view. Search CSV export uses the columns currently displayed. Configure columns drops Last activity (same as Updated) and adds Created and Resolved.

**Tracking:** **NG-755** / **NGB-101** / **NGF-008** / **NGF-013**. Public installer sample compose stays on **`latest`**. Candidate tag: **`dev-230ec88`**.

## Assets

- No GIF or screenshot required for this patch.

## Added

- Search URL `cols` (pipe-separated Configure column labels) restored with saved views (**NG-755**).
- Saved-filter `queryJson.visibleColumns` encoded into canonical search URLs (**NG-755**).
- Configure columns options: **Created** and **Resolved** (`completedAt`) (**NG-755**).
- Search export accepts optional `columns` so CSV matches the table (**NG-755**).

## Changed

- Filters open appends saved `columnsJson` when the canonical URL lacks `cols` (legacy views) (**NG-755**).
- Configure columns no longer lists **Last activity** (aliased to **Updated**) (**NG-755**).

## Fixed

- Opening a saved filter restored criteria but reset table columns to defaults (**NGB-101**).
- Export always emitted Workspace, Key, Summary, Type, Status, Reporter, Assignee, Updated and ignored displayed columns (**NGB-101**).

## Verified

- Local stack (`cicd-pipeline-local.sh --deploy`).
- Destin + UAT promote: **`dev-230ec88`**.

## Upgrade notes

- Pin `nogira-core`, `nogira-ui`, `nogira-worker`, and `nogira-mcp` to **0.8.12** together when the Hub tags exist, then `docker compose pull && docker compose up -d` (or keep sample `:latest` if that is your eval setup).
- Public installer `docker-compose.yml` is **not** version-pinned in this release (sample stays on **`latest`**).
- No manual SQL for NoGira schema migrations (applied on core startup).
- PostgreSQL remains pinned at `postgres:14` — do not change major version without a PostgreSQL migration procedure ([deployment.md](../deployment.md)).
- Older saved views without `cols` / `columnsJson` keep default columns until re-saved once.
