# NoGira 0.3.4

**Release date:** 2026-06-15

**NG-722 Plan Board fixes** (**NGF-079**) — dependency warning semantics and fast scheduling polish for the Plan board.

**Tracking:** **NG-722-P11**, **NG-722-P12**, **NGF-079**.

## Added

- **Ghost schedule bars:** fully unscheduled Plan rows now show a translucent 30-day draft bar after a short hover delay in the timeline area.
- **Fast Plan scheduling:** click a ghost bar to persist `startDate` / `dueDate` immediately, or drag it horizontally and release to schedule the row.

## Changed

- **Dependency warnings:** red dependency lines and `Dates overlap` dropdown warnings now use the schedule predicate `source.dueDate > target.startDate`.
- **Ghost interactions:** draft schedule bars are single-row owned, clear on row leave / Escape / pointer cancel, and do not show resize handles, dependency handles, progress, or selection styling before persistence.

## Fixed

- **False dependency overlap warnings:** dependency lines no longer turn red just because rendered bars overlap horizontally.
- **Plan scheduling friction:** unscheduled activity rows can be scheduled directly from the timeline without opening the activity detail panel.

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.3.4** and `REACT_APP_VERSION` on the UI service, then run `docker compose pull && docker compose up -d`.
- **No new Prisma migration** — UI-only Plan board polish.
- Requires **0.3.3** images or a fresh **0.3.4** pull of the full stack.
