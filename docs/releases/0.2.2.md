# NoGira 0.2.2

**Release date:** 2026-06-13

**MCP wiki attachment images** (**NGF-026** / **NGF-067** / **NG-721-P11**) — agents can upload, list, replace, and safely delete wiki attachments over MCP, then publish markdown with figure markup that renders in the product UI.

**Tracking:** **NG-721-P11**, **NGF-026**, **NGF-067**.

## Added

- **MCP tools:** `uploadWikiAttachment`, `listWikiPageAttachments`, `replaceWikiAttachmentContent`, `deleteWikiAttachment` (referenced-attachment guard; `ATTACHMENT_REFERENCED` when `deleteIfReferenced` is false).
- **Core MCP routes:** `POST/GET /api/mcp/wiki/pages/:pageId/attachments`, `PUT/DELETE /api/mcp/wiki/attachments/:id` (base64 JSON; delegates to existing wiki attachment services).
- **`suggestedMarkup`** / **`suggestedLinkMarkup`** on upload — canonical `<figure class="nogira-img-align-*">` + `/api/wiki/attachments/{id}/download?variant=preview` for images.

## Changed

- **`nogira/docs/mcp.md`** — documents attachment tools and wiki image workflow for AI clients.
- **JSON body limits** on **nogira-core** and **nogira-mcp** — sized for `NOGIRA_UPLOAD_MAX_BYTES` base64 uploads (~33% wire overhead).

## Fixed

- **P9-BUG-003** — MCP agents can upload wiki attachments and embed figure markup so repo-relative image paths (`assets/…`) render on hosted wiki.

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.2.2** and `REACT_APP_VERSION` on the UI service, then `docker compose pull && docker compose up -d`.
- **No new Prisma migration** — reuses existing wiki attachment storage (**NG-513**).
- Hub must publish images at **0.2.2** after dev/uat validation (`cicd-release.sh --version 0.2.2`).
- MCP clients publishing images: `uploadWikiAttachment` → embed `suggestedMarkup` → `updateWikiPage`.
