# NoGira 0.7.3

**Release date:** 2026-10-27

**Move activity to another workspace** — from the mobile actions sheet or the desktop Actions / row menu, pick a target workspace, type, and status. The activity keeps the same id and gets a new key in the target workspace.

**Tracking:** **NGB-065**.

No screenshot.

## Added

- `GET /api/activities/move-targets` lists workspaces where you can create activities.
- `POST /api/activities/move-to-workspace` moves one or more activities (same id, new key; clears parent/children, assignee, and sprint membership; keeps reporter and field values).
- Mobile: **Move** on the swipe actions sheet (before Clone), with Back, taller sheet, and an inline status list that shows about four statuses on the same screen.
- Desktop: **Move** before Clone on the bulk Actions menu and the row ⋯ menu (shared panel; multi-select uses one target).
- Mobile activities and home search: total count after Done; filter workspace selector navigates to that workspace’s activities list.
