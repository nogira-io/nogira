# NoGira 0.1.9

**Release date:** 2026-05-26

## Added

- **Portfolio workspace templates (MVP1)** — Portfolio workspaces now have a `portfolioTemplate` preset with three options:
  - **Basic SAFe (default)** — Initiative → Epic
  - **Full SAFe** — Theme → Initiative → Epic
  - **Waterfall** — Project → Phase
- **Portfolio template selector (Create workspace)** — when creating a **Portfolio** workspace, the UI prompts for the template preset (hidden for non-Portfolio types).

## Changed

- **Portfolio create cloning** — Portfolio workspace create now clones the correct default schemes (type / flow / screen) based on the selected template (same “clone from DEFAULT catalogue” idea as Development workspaces).
- **Activity type rename in catalogue** — `MILESTONE` is renamed to **`PHASE`** across catalogue defaults (seeds, schemes, screens, flows). Workspace Plan markers (`WorkspaceMilestone`) are unchanged.
- **Simulator portfolio bootstrap** — `nogira-simulator` now creates the demo portfolio workspace with an explicit `portfolioTemplate` (via `RUNTIME_PORTFOLIO_TEMPLATE=SAFE_BASIC`).

## Fixed

- **Waterfall hierarchy correctness** — Waterfall portfolio presets enforce **Project → Phase** only (no Deliverable in the Waterfall type scheme).

## Upgrade notes

- **Public installer default version:** edit `docker-compose.yml` tags to `0.1.9` on `nogira-core`, `nogira-ui`, and `nogira-notification-worker`; set `REACT_APP_VERSION` to `'0.1.9'`.
- Run `docker compose pull && docker compose up -d`.
- **No manual NoGira SQL** — Prisma `migrate deploy` runs on core startup.
- **PostgreSQL** stays on `postgres:14` — do not bump to PG 15+ without a PostgreSQL major-upgrade procedure ([deployment.md](../deployment.md)).
- From **0.1.8:** existing volumes compatible; mixed image versions unsupported.
