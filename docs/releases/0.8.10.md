# NoGira 0.8.10

**Release date:** 2026-11-09

**Wiki open speed + shared loading + colder main bundle** — Wiki pages load without pulling the rich editor into the first paint; deep links that used `/wiki/pages/:id` redirect to the canonical `/wiki/:id` path; boards, Wiki, and mobile lists share one skeleton loading system; Insights charts and React Flow leave the main SPA chunk so cold home/wiki opens transfer less JavaScript.

**Tracking:** **NG-748** / **NG-749** / **NG-751** / **NG-752** / **NGB-097** / **NGB-099** / **NGF-043** / **NGF-046** / **NGF-082**. Public installer sample compose stays on **`latest`**. Candidate tag: **`dev-230ec88`**.

## Assets

- No GIF or screenshot required for this patch.

## Added

- Shared `NgLoading` / `NgSkeletonLayout` with seven screen-matched layouts (`activity-mobile`, `kanban`, `scrum-backlog`, `activity-table`, `wiki-search-mobile`, `wiki-tree`, `wiki-page`) (**NG-751**).
- Route-level lazy Wiki pages + `LazyWikiBlockEditor` / `LazyActivityEditor` so Toast UI stays off the view path (**NG-749-P2**).
- Intelligent Edit-intent prefetch for Wiki editor chunks (**NG-749-P4**).
- Compat redirect `/workspaces/:id/wiki/pages/:pageId` → `/wiki/:pageId` (**NG-749-P0** / **NGB-099**).
- `LazyWorkflowModal` so opening an activity workflow graph does not keep React Flow in the main bundle (**NG-752**).
- QA harnesses: `npm run wiki:smoke` / `wiki:acceptance` under `nogira-testing/performance/wiki/` (**NG-751** Ph7).

## Changed

- Wiki open path dedupes loading waterfalls (body vs nav, parallel caps, deferred sidebar work) (**NG-748**).
- Insights and activity-flow settings routes use `React.lazy` + `NgLoading variant="page"` (**NG-752**).
- MCP wiki search `urlPath` uses canonical `/wiki/{pageId}` (not `/wiki/pages/…`) (**NG-749-P0**).
- Production main chunk drops recharts/reactflow into async chunks (gzip main ≈ **−17%** vs pre–NG-752 baseline on QA).

## Fixed

- Wiki UI deep link shaped like the REST API (`/wiki/pages/:id`) returned 404 (**NGB-099**).
- Wiki cold open latency dominated by eager Editor / main heavies — mitigated (**NGB-097**; conditional exit: mobile S4 ≈ **−12%** under 4G+CPU4× after NG-752).

## Verified

- Local UI + QA: `wiki:smoke` PASS; light `wiki:acceptance` (toast-on-view 0; Edit cache hit).
- Dist assert: recharts/reactflow absent from `index-*.js`; Insights / FlowEditor / WorkflowModal async chunks present.
- Destin: **`dev-230ec88`**.

## Upgrade notes

- Pin `nogira-core`, `nogira-ui`, `nogira-worker`, and `nogira-mcp` to **0.8.10** together when the Hub tags exist, then `docker compose pull && docker compose up -d` (or keep sample `:latest` if that is your eval setup).
- Public installer `docker-compose.yml` is **not** version-pinned in this release (sample stays on **`latest`**).
- No manual SQL for NoGira schema migrations (applied on core startup).
- PostgreSQL remains pinned at `postgres:14` — do not change major version without a PostgreSQL migration procedure ([deployment.md](../deployment.md)).
