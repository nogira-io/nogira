# NoGira 0.3.6

**Release date:** 2026-06-15

**NG-722 wiki Export to PDF** (**NGF-079** / **NG-722-P14**) — export the current wiki page as a downloadable PDF from the page header actions menu.

**Tracking:** **NG-722-P14**, **NGF-079**.

## Added

- **`GET /api/wiki/pages/:pageId/export/pdf`** — server-side PDF export with `VIEW_WIKI` permission gate, sanitized filename, and metadata header (creator, last updated, workspace).
- **Wiki page actions menu** — **Export to PDF** appears first (before **New sub-page**), with loading state and semantic error toasts.
- **Core PDF stack** — `puppeteer-core` + Alpine Chromium in the core image; singleton browser lifecycle; footer page numbers; 5 MiB export size guard.

## Changed

- **Wiki page `…` menu** — visible to any wiki viewer (`VIEW_WIKI`), not only editors; edit/manage actions remain permission-gated below the divider.
- **Core Docker image** — adds Chromium runtime dependencies for headless PDF generation (`PUPPETEER_EXECUTABLE_PATH=/usr/bin/chromium`).

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.3.6** and `REACT_APP_VERSION` on the UI service, then run `docker compose pull && docker compose up -d`.
- **No new Prisma migration** — export is a read-only API + UI surface.
- Requires **0.3.5** images or a fresh **0.3.6** pull of the full stack.
- Core image is larger due to Chromium; allow extra pull time on first upgrade to **0.3.6**.
