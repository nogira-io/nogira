## Added

- **nogira-core** — Express API, Prisma, PostgreSQL, JWT authentication with directory abstraction (INTERNAL; LDAP-ready shape).
- **nogira-ui** — Authenticated product shell for instance and user management.
- User management APIs (create, edit, delete; system admin flows).
- Instance bootstrap on first startup (admin recovery path).
- Workspace CRUD with hierarchy support.
- Workspace template system with automatic scheme cloning on workspace creation.
- Authentication and authorization middleware (JWT, system admin gates).

## Changed

- Initial domain-oriented API structure and multi-repo product layout.

## Upgrade notes

- Pre-public installer era; not distributed via `nogira-io/nogira` compose.
