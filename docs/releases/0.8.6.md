# NoGira 0.8.6

**Release date:** 2026-11-04

**Board card status + priority** — Kanban and Scrum active-sprint cards show a compact status chip (top-right) and the activity priority name with color swatch (bottom-right). Board/sprint list APIs include `priorityOption` so cards no longer show Priority **None** when a priority is set.

**Tracking:** **NG-742**, **NGB-093**, **NGF-007**, **NGF-016**. Public installer sample compose stays on **`latest`**.

## Assets

- No GIF or screenshot required for this patch.

## Added

- Board / sprint activity list projection includes **`priorityOption`** / **`priorityOptionId`** (**NG-742**).

## Changed

- **ActivityCard** — top-right: compact `StatusLabel` (~80% of default); bottom-right: priority **name then color swatch** at ~90% density (**NG-742** / **NGB-093**).
- Priority sort on boards uses `priorityOption.weight`.

## Verified

- Local: `GET /api/boards/:id/activities` returns `priorityOption` after set; UI redeployed for card chrome.

## Upgrade notes

- Pin `nogira-core`, `nogira-ui`, `nogira-worker`, and `nogira-mcp` to **0.8.6** together when the Hub tags exist, then `docker compose pull && docker compose up -d` (or keep sample `:latest` if that is your eval setup).
- Public installer `docker-compose.yml` is **not** version-pinned in this release (sample stays on **`latest`**).
- No manual SQL for NoGira schema migrations (applied on core startup).
- PostgreSQL remains pinned at `postgres:14` — do not change major version without a PostgreSQL migration procedure ([deployment.md](../deployment.md)).
