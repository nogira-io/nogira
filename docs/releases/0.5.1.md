# NoGira 0.5.1

**Release date:** 2026-10-23

**Standard screen save** (**NGB-061**) — creating or editing a Standard screen keeps a custom field such as Company. Parent stays with the other locked system fields. The save uses this instance's field ids.

**Tracking:** **NGB-061**, **NGF-000**.

## Fixed

- Creating a Standard screen after adding Company (`CF_COMPANY`) saves the screen and keeps Company. It no longer stops with “Locked system fields cannot be removed from STANDARD screens”.
- Editing a Standard screen and adding Company saves. The fields request uses this instance's ids.
- The editor preloads Parent with Summary, Description, Reporter, Assignee, Priority, Labels, Due Date, Start Date, and Resolution. After create, any locked field the server returned and the editor omitted is included in the fields save. Switching the screen to Transition removes Parent with those other keys.

## Upgrade notes

- Dev and UAT stay on the last deployed tag until you promote this candidate. The public installer tags in `docker-compose.yml` stay on the last published semver until `cicd-release.sh`.
- No Prisma migration. This is a product UI change in the activity screen editor.
