# NoGira 0.1.2

**Release date:** 2026-05-18

## Added

- **Kanban board** — columns by workflow status, drag-and-drop transitions, board-level configuration.
- Board hub and workspace board integration with RBAC capabilities.
- Activities board enhancements (filtering, workspace activity lists at scale).

## Changed

- Board APIs aggregated for `/home/boards` and favorites integration.
- Hosted smoke validation aligned with Kanban paths.

## Fixed

- Post-create list refresh and highlight behaviour on workspace activities.

## Upgrade notes

- Same semver required on `nogira-core`, `nogira-ui`, and `nogira-notification-worker` images.
- No manual migration steps for patch/minor NoGira upgrades when staying on PostgreSQL 14.
