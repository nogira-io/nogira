# NoGira 0.3.9

**Release date:** 2026-10-22

**NG-726 mobile integration** (**NGF-082**) — phone challenge play, activity feed fixes, and challenge step images. Desktop layout stays the same.

**Tracking:** **NG-726-P12**, **NG-726-P13**, **NG-726-P14**, **NGF-082**.

## Added

- Phone drawer **Challenges**, under Whiteboards. Joining by code or QR opens `/home/search` on a phone and `/home` on desktop.
- Phone queue card, and a 180×45 running HUD centered in the header.
- Challenge settings section **Missions and scoring**: the three missions, their events, the points formula, and the step image.
- A new challenge stores the three sample GIFs as files. **Replace image** shows the chosen file immediately. Recommended size is 1:1, 1470 × 1470.
- Explore scoring for a mobile search filter, each of the five status categories, the whiteboard list, one whiteboard, Account, a profile photo, and a personal access token. Each action still scores once per player.

## Changed

- Phone login and `/` open `/home/search?assigneeIds=currentUser`. Opening `/home/search` later without that query stays unfiltered.
- The phone activity feed loads the next page as you scroll.
- Mobile wiki create asks for a workspace and prefills the one already selected.
- Challenge settings order is Challenge details, Join & share, Missions and scoring, Lifecycle.

## Fixed

- Older activities stay in the Last Activity feed. Recency is filled when it was missing, and moved forward when the row was updated later.
- Adding another comment during a challenge saves the comment and does not return an error after that action has already scored.

## Upgrade notes

- Dev and UAT stay on the last deployed tag until you promote this candidate. The public installer tags in `docker-compose.yml` stay on the last published semver until `cicd-release.sh`.
- Core startup applies Prisma migrations `20261020120000_ng726_activity_recency_backfill` and `20261022030000_ng726_challenge_step_image`.
- Challenges created before this release keep the public step GIF until you replace it.
