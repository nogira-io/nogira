# NoGira 0.4.0

**Status:** Development paused — partially implemented, not publicly released.
**Development paused:** 2026-10-18
**Latest published installer version:** 0.3.9
**MOBA Foundation** (**NGF-080** / **NGF-014**) — Initial platform capabilities for agent-oriented task management, workflow orchestration, activity relationships, MCP traversal, and authentication improvements.
Development of the complete MOBA solution has been paused. Some foundational changes have been implemented, while the MOBA Web UI, complete agent orchestration, and production-ready worker architecture remain unfinished.

**Tracking:** **NG-724**, **NG-724-P1**, **NG-724-P2-B**, **NG-724-P4**, **NG-724-P5-B**, **NG-724-P5-C**, **NG-724-P11**, **NG-725**, **NGF-080**, **NGF-014**.

## Added
- **Agent Task activity type (`AGENT_TASK`)** — Introduced in the Software workspace template, including MOBA-specific workflow statuses, transitions, and screen scheme configuration (**NG-724-P1**).
- **MOBA workflow states** — Added Manual Plan Refinement, Build Failed, and Release Failed to support explicit failure handling and recovery (**NG-724-P1**).
- **Blocks relationship propagation** — Parent Story status updates when Agent Task blocker relationships change (**NG-724-P4**).
- **MCP activity hierarchy traversal** — Added `GET /api/mcp/activities/:id/parent` to retrieve parent relationships (**NG-724-P11**).
- **MCP wiki hierarchy traversal** — Added:
  - `GET /api/mcp/wiki/pages/:id/parent`
  - `GET /api/mcp/wiki/pages/:id/children`
  These endpoints support agent navigation through wiki hierarchies (**NG-724-P11**).

## Changed
- **Session authentication** — Invalid or expired JWT tokens on `GET /api/auth/me` now return `401 Unauthorized` rather than `403 Forbidden` (**NG-724-P5-C**).
- **UI authentication handling** — Updated authentication handling so stale sessions redirect affected users to `/login` instead of `/forbidden` (**NG-724-P5-C**).
- **MCP relationship filtering** — Extended `GET /api/mcp/activities/:id/links` with optional query parameters:
  - `targetType`: `activity` or `wiki`
  - `relationType`: `blocks`, `blocked_by`, `relates_to`, or `documents`
  Existing behavior remains unchanged when filters are omitted (**NG-724-P11**).

## Fixed
- **Stale JWT authentication issue** — Fixed cases where expired or invalid session tokens stored in `localStorage` caused anonymous users to reach `/forbidden` instead of `/login` following stack recreation or secret rotation (**NG-724-P5-C**).

## Experimental Components — Not Included in the Public Installer
The following components were developed or partially implemented as part of the MOBA initiative but are not part of the published installer.

### MOBA host-native worker
- Initial `nogira-moba` host-native worker implementation (**NG-724-P2-B**, **NG-724-P5-B**).
- Designed to run directly on an operator-controlled machine rather than inside the standard Docker Compose stack.
- Uses polling to communicate with the NoGira instance.
- Reads execution rules and context from the operator environment.
- Initial support for planning, implementation, and release behaviors.
- Installation path: `~/Desktop/.nogira-moba`.
- Introduced `MOBA_OVERWRITE_BEHAVIORS` (default `true`) to control whether deployment overwrites locally modified behavior files.

**Status:** Experimental. Further worker development and integration are paused.

### MOBA Web UI and orchestration
- MOBA board implementation is not complete.
- End-to-end agent orchestration is not complete.
- Integration between the MOBA interface, Agent Tasks, and host-native workers remains unfinished.

**Status:** Paused. Not included in the public installer.

### Internal MCP delivery toolkit
Added internal utilities under `nogira-handbook/scripts/mcp/` (**NG-725**):
- `sync-context-wiki` — Publishes plans and feature documentation to the UAT wiki.
- `sync-release-demo` — Synchronizes release documentation to the demo wiki.
- `create-plan-agent-tasks` — Creates Story execution graphs for agent-oriented workflows.

These utilities support internal development and delivery processes.

**Status:** Internal tooling. Not included in the public installer.

## Development Status
The MOBA initiative was paused on 2026-10-18 due to the additional implementation effort required to complete the Web UI, agent orchestration, and host-native worker architecture.
The pause does not imply that all related platform improvements have been reverted.
Completed foundational changes may be retained independently of the full MOBA solution, subject to integration and release validation.
Future MOBA development may resume under **NGF-080**.
