# NoGira 0.4.0

**Release date:** 2026-06-28

**NG-724 MOBA foundation tranche** (**NGF-080** / **NGF-014**) — **Agent Task** workflow in the platform, auth shell fix for stale JWT sessions, MOBA blocker relationship propagation, and MCP relationship/hierarchy traversal tools for agent orchestration.

**Tracking:** **NG-724-P1**, **NG-724-P4**, **NG-724-P5-C**, **NG-724-P11**, **NGF-080**, **NGF-014**.

## Added

- **Agent Task activity type (`AGENT_TASK`)** — Software template seeds type, MOBA workflow statuses/transitions, and screen scheme wiring (**NG-724-P1**).
- **MOBA workflow states** — explicit failure/refinement states (Manual Plan Refinement, Build Failed, Release Failed) aligned with **NGF-080** failure philosophy (**NG-724-P1**).
- **Blocks relationship propagation** — parent Story status updates when Agent Task blockers change (**NG-724-P4**).
- **MCP relationship/hierarchy tools** — `GET /api/mcp/activities/:id/parent`, `GET /api/mcp/wiki/pages/:id/parent`, and `GET /api/mcp/wiki/pages/:id/children` so agents can traverse activity and wiki trees up and down (**NG-724-P11**).

## Changed

- **Session JWT auth semantics** — invalid/expired session tokens on `GET /api/auth/me` return **401 Unauthorized** (authentication), not **403 Forbidden** (**NG-724-P5-C**).
- **UI auth interceptor** — **403** on `/api/auth/me` and `/api/auth/me/*` clears stale token and redirects to **`/login`** instead of **`/forbidden`** (**NG-724-P5-C**).
- **MCP activity links filtering** — `GET /api/mcp/activities/:id/links` now accepts optional **`targetType`** (`activity`|`wiki`) and **`relationType`** (`blocks`|`blocked_by`|`relates_to`|`documents`) query filters; no params preserves prior behavior (**NG-724-P11**).

## Fixed

- Stale JWT in `localStorage` sending anonymous users to **`/forbidden`** on root visit instead of **`/login`** after stack recycle / secret rotation (**NG-724-P5-C**).

## Companion (not in this compose bundle)

- **`nogira-moba`** host-native worker (**NG-724-P2-B** Ph6–Ph6.3, **NG-724-P5-B**) installs separately under `~/Desktop/.nogira-moba` — see **NGF-080** architecture guide.
- **MOBA behavior overwrite control** — `MOBA_OVERWRITE_BEHAVIORS` env (default `true`) lets operators preserve hand-edited installed `behaviors/**` across `--deploy` (**NG-724-P11**).
- **MCP delivery toolkit** — `nogira-handbook/scripts/mcp/` provider utilities (`sync-context-wiki`, `sync-release-demo`, `create-plan-agent-tasks`) for publishing plans/features to UAT wiki, releases to demo wiki, and creating Story execution graphs; idempotent, JSON output (**NG-725**, internal delivery tooling).

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.4.0** and `REACT_APP_VERSION` on the UI service, then run `docker compose pull && docker compose up -d`.
- **No new Prisma migration** in this slice — template seeds apply on core startup for new workspaces; existing workspaces unchanged unless operator re-seeds.
- Requires **0.3.7** images or a fresh **0.4.0** pull of the full stack.
- After upgrade, clear stale browser `localStorage.token` once if you still see unexpected redirects (should self-heal via **NG-724-P5-C**).
