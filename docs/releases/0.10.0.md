# NoGira 0.10.0

**Release date:** 2026-11-11

**My Work Universal Kanban** (**NGF-098**, **NG-757** P0–P9) — Desktop `/home/my-work` becomes a five-column personal Kanban across discoverable workspaces, with Customize parity, workflow-valid drag-and-drop, and shared polish on workspace Kanban / Active Scrum (solid column accents, SegmentedTabs, Jira-like drop targets). Sprint close Activities Review shows the human activity key.

**Tracking:** **NG-757** P0–P9, **NGF-098**, DELIVERY-259 / DELIVERY-260.

## Added

- **Desktop My Work Kanban** — five columns (Needs Attention, Ready to Start, Active Work, Waiting, Recently Completed) with per-column pagination and hybrid Waiting (**NG-757-P1/P2**).
- **Customize** — BoardSettings-like modal for column order/visibility/labels/colors and optional card fields (always-on status/priority/due) (**NG-757-P5–P7**).
- **Shared Kanban chrome** — `shared/components/kanban` card/column shell + drag-session tint tokens reused by My Work (**NG-757**).
- **Column API** — `GET /api/my-work/columns/:columnKey` with discoverable workspace scan (**NG-757-P1**).

## Changed

- **Settings2** — Activities column settings and board toolbar settings use Settings2 (local settings affordance) (**NG-757-P8**).
- **Scrum toolbar** — Backlog / Active Sprint / Metrics use SegmentedTabs; Complete Sprint sits beside the tab island when an active sprint exists (**NG-757-P8**).
- **Metrics unit** — Activities / Story Points use SegmentedTabs (**NG-757-P8 Ph6e**).
- **Board column accents** — Kanban / Active Scrum header stripes use saturated colors (legacy pastel remap) matching My Work (**NG-757-P8**).
- **Jira-like drag** — Valid columns tint blue, cards hide, available statuses show as drop targets on Kanban, Active Scrum, and My Work (**NG-757-P8**).
- **Empty sprint drop** — Dragging backlog items onto an empty sprint column opens New Sprint and adds them after confirm (**NG-757-P8**).

## Fixed

- Activities Review ceremony cards showed UUID instead of activity key — now shows `task.key` (**NG-757-P9**).

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`** (do not pin tags in the sample).
- Promote candidate images together (core, ui, worker, mcp). My Work column API ships with core; UI expects the new routes.
- No manual SQL for this slice (prefs JSON only for My Work Customize). PostgreSQL remains `postgres:14`.
