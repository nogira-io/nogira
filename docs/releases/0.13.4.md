# NoGira 0.13.4

**Release date:** 2026-11-20

**Fix:** Critical/High security remediation from the NGDEV-461 assessment (**NGF-053**): workspace authz, JWT secrets, admin boundaries, wiki PDF SSRF, and runtime dependency upgrades (**NGDEV-467…471** / **NGB-108…112**). No GIF.

## Fixed

- **Workspace / activity authz:** Guests and non-members cannot mutate activities, boards, or MCP write paths that previously only required “workspace readable.” UI fails closed on capabilities (read-only chrome, no create/edit affordances that the API refuses).
- **Session JWT:** No hard-coded `dev-secret` fallback. Empty `JWT_SECRET` generates and persists a strong secret; known sample secrets are refused in production. Tokens forged with published samples are rejected (**401**).
- **ADMIN vs SYSTEM_ADMIN:** ADMIN manages USER/ADMIN instance-wide; can see System Admins; cannot take over System Admin accounts (password/email/role). UI Settings → Users follows server `allowedActions` (no surprise **403**). Create User remains SYSTEM_ADMIN-only. System Admin rows: archive/restore only where policy allows (P8).
- **Wiki PDF export:** Export HTML is sanitized; Puppeteer runs with JavaScript off and blocks non-`data:` network requests (SSRF).
- **Dependencies:** Core upgrades multer, sharp, nodemailer (and related); mcp SDK refreshed. High-level `npm audit` on core is clean.

## Changed

- Installer / local / QA compose: prefer empty `JWT_SECRET` so core can auto-generate (see `.env.example`).
- Local CI: route-authz audit gate for core; advisory runtime `npm audit` in the pipeline.

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`**.
- Promote matching **core + ui + worker + mcp** images together.
- After upgrade: leave `JWT_SECRET` empty (or set a long random value ≥32 chars). Do not use `dev-secret` / `change-me-*` sample values on production-like hosts.
- Smoke: guest cannot edit private workspace activities; forge sample JWT → **401**; ADMIN Settings → Users shows all users without System Admin takeover controls; wiki Export PDF still works; activity/wiki uploads still work.
