## Added

- **Plan Board timeline editing:** drag/resize interactions are separated from row selection so moving or resizing a bar does not accidentally open the activity panel.
- **Plan Board dependencies:** dependency handles create `BLOCKS` links directly on valid drop, without opening the Add Link modal.
- **Dependency details dropdown:** clicking a dependency line opens a lightweight details dropdown with source, target, relation type, overlap warning, and remove action.

## Changed

- **Dependency connector rendering:** connectors use rendered bar rectangles for source/target anchors, manual arrowheads, inverse-S overlap routing, and red warning color for overlapping/overdue dependencies.
- **Dependency dropdown dismissal:** the dependency details dropdown closes on outside click and on `Escape`.

## Fixed

- **Plan Board selection safety:** timeline edit gestures suppress row selection to avoid accidental activity panel changes.
- **Overlap connector readability:** overlapping dependencies avoid large U-shaped routes and instead use compact inverse-S routing.

## Upgrade notes

- Bump **all four** `nogira/nogira-*` tags in `docker-compose.yml` to **0.3.3** and `REACT_APP_VERSION` on the UI service, then `docker compose pull && docker compose up -d`.
- **No new Prisma migration** — UI and relationship DTO polish only.
- Requires **0.3.2** images or a fresh **0.3.3** pull of the full stack.
