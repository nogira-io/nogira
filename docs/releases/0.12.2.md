# NoGira 0.12.2

**Release date:** 2026-11-16

**Wiki shared draft + exclusive editing** (**NGF-100**, **NG-774** P0–P3 / P5 / P6A) and **block chrome actions rail** (**NG-772-P11**). No GIF.

## Added

- One shared unpublished draft per Wiki page with hybrid IndexedDB + server autosave, explicit **Publish** to immutable published revisions, and **Discard** (**NG-774-P1/P2**).
- Exclusive human edit lease with heartbeat renew, request/handoff modal, and ownership banner when another editor holds control (**NG-774-P1/P3**).
- Deployment ENV timings (and `GET /api/wiki/client-config`): draft local idle 500ms, server autosave 30s, max unsaved 60s, heartbeat 30s, lease TTL 120s, inactive release 5 min (exposed; enforce in **P6B**) (**NG-774** / Q774.8).
- Immediate **Request control** when clicking **Edit** on a locked page (no silent wait) (**NG-774-P6A**).
- API coverage: draft get/put, publish, discard, edit-lease acquire/renew/release/request/handoff, client-config (**NG-774-P5**).
- Product e2e/API specs for draft lifecycle and lease handoff (`nogira-testing`) (**NG-774-P5**).
- Single top-right block actions rail (move / columns / copy / delete) without duplicate Copy chrome (**NG-772-P11**).

## Changed

- Wiki Edit enters the draft domain under a lease; published Markdown updates only on **Publish** (or MCP publish path — conflict polish still **P4**).
- Handbook/Ansible compose pass through `WIKI_DRAFT_*` / `WIKI_EDIT_*` env vars to core.

## Fixed

- Locked-page Edit no longer appears idle for ~heartbeat interval before ownership UI (**NG-774-P6A**).

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`** (do not pin tags in the sample).
- Promote matching **core + ui + worker + mcp** images together.
- Core applies Prisma migration `20261114193000_ng774_wiki_shared_draft_publish_lease` on startup (`WikiPageDraft`, `WikiPagePublishedRevision`, `WikiPageEditLease`, `WikiPageEditHandoffRequest`).
- Optional deploy env (defaults match product):  
  `WIKI_DRAFT_LIFECYCLE_ENABLED`, `WIKI_DRAFT_LOCAL_IDLE_MS`, `WIKI_DRAFT_AUTOSAVE_IDLE_MS`, `WIKI_DRAFT_MAX_UNSAVED_MS`, `WIKI_EDIT_HEARTBEAT_MS`, `WIKI_EDIT_LEASE_TTL_MS`, `WIKI_EDIT_INACTIVE_RELEASE_MS`.
- Still open (not in this release): **NG-774-P4** MCP/conflict UX; **NG-774-P6B** `WIKI_EDIT_OWNERSHIP_POLL_MS` + inactive-release enforcement; **NG-772-P6** responsive/a11y/perf e2e.
