# NoGira 0.13.3

**Release date:** 2026-11-20

**Fix:** Mobile drawer selection + filter persistence, and context-aware activity detail navigation (**NGDEV-454-PX7** / **NGB-113**, **NGDEV-462** / **NGB-107**). No GIF.

## Fixed

- **Mobile drawer:** On Wiki / Whiteboards, only that knowledge row is selected (ALL / status categories are not highlighted at the same time).
- **Mobile filters:** Category taps only set `statusCategories` and keep other remembered filters (including cleared Myself). First login still defaults `assigneeIds=currentUser`.
- **Filter Activities:** Workspace selector clear **X** means all spaces and opens global Search with remaining filters.
- **Activity detail overlay:** Related links, parent, children, and breadcrumbs stay inside the right panel when opened from an overlay host; maximize / own-key full-page actions remain explicit (**NGDEV-462**).
- **Mobile wiki:** Chrome / actions polish for phone wiki reading and actions (**NGDEV-462-P4**).

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`**.
- Promote matching **core + ui + worker + mcp** images together.
- After upgrade (mobile): open Wiki from the drawer → only Wiki selected; clear Myself → tap a category → Myself stays off; clear workspace in Filter Activities → `/home/search`.
- After upgrade (desktop): open an activity from Search overlay → click a related activity → panel updates in place (no full-page jump unless maximize / key action).
