**Release date:** 2026-10-30

**Mobile own-work assignee pin, first-login Search landing, outbound notification jobs tabs, and operator CLC/cleanup tooling** — Ships **NG-734-P19**, **NG-734-P22**–**P25** (**NGB-088**–**091**), plus hosted env cleanup (**NG-734-P21**) and phased CLC enrollment load scaffolding (**NG-734-P18** / **NG-734-P20** enrollment slice; challenge phases paused for later rework).

## Assets

- No GIF or screenshot required for this patch.

## Added

- **Hosted env cleanup** — `nogira-handbook/scripts/cicd-cleanup.sh` resets a hosted env DB (compose down → rename RDS DB → fresh DB → clear install markers → compose up → print install token) (**NG-734-P21**).
- **CLC phased enrollment load** — `nogira-testing` `perf:clc:event` / `perf:clc:phase` registration journey with operator `yes` gates and JWT cohort handoff (**NG-734-P18** / **P20** enrollment).

## Changed

- **Outbound delivery jobs** — `/settings/notifications` jobs use **SegmentedTabs** (All / Pending / Processing / Done / Failed) with `statusCounts`, pager, and Actions (delete selected, clear sent+failed, clear unsent); no search box (**NG-734-P19**). API `GET /api/system/notifications/jobs` accepts optional `status` and returns `statusCounts`.
- **Mobile own-work pin** — Challenge enroll/join lands on `authenticatedHomePath` with `assigneeIds=currentUser` on phones (**NG-734-P22**). Drawer categories and Search/Activities keep that pin (**NG-734-P23**). Layout + session remember so Wiki/Whiteboards round-trips do not drop it (**NG-734-P24**).
- **Mobile wizard-off first login** — After `POST /api/onboarding/wizard-off-bootstrap`, phones stay on `/home/search?assigneeIds=currentUser` instead of opening ONBOARDING Kanban; desktop still opens the board. Topbar **Onboarding tasks** still opens the board. Provision + redirected marker unchanged (**NG-734-P25** / **NGB-091**).

## Fixed

- **NGB-088** — Mobile challenge enroll redirected without assignee filter.
- **NGB-089** — Mobile sidebar category navigation missing `assigneeIds=currentUser`.
- **NGB-090** — Returning from mobile Wiki/Whiteboards dropped the assignee pin.
- **NGB-091** — Mobile first login with wizard OFF redirected to ONBOARDING Kanban after Search landing.

## Upgrade notes

- Pin `nogira-core`, `nogira-ui`, `nogira-worker`, and `nogira-mcp` to **0.8.3** together when the Hub tags exist, then `docker compose pull && docker compose up -d`.
- No manual SQL for NoGira schema migrations (applied on core startup).
- PostgreSQL remains pinned at `postgres:14` — do not change major version without a PostgreSQL migration procedure ([deployment.md](../deployment.md)).
