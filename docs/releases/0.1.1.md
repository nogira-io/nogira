# NoGira 0.1.1

**Release date:** 2026-05

## Added

- **Hosted demo instance** — `demo.nogira.io` style deployment on POC infrastructure (EC2, RDS, Caddy proxy).
- Shell CI/CD split: `cicd-deploy.sh` (dev/uat) and `cicd-release.sh` (demo semver promotion).
- Environment-specific runtime layout under `/opt/docker-apps/<env>.nogira.io/`.

## Changed

- Demo stack uses immutable semver image tags after release promotion (not floating `latest`).

## Upgrade notes

- Public self-hosted installer (`nogira-io/nogira`) not yet published at this version.
