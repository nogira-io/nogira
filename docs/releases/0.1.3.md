# NoGira 0.1.3

**Release date:** 2026-05

## Added

- **Plan view** (`/plan`) — workspace activity tree with planning dates and progress rollup.
- **Milestones** and **releases** as timeline markers (CRUD APIs, driver assignment, colours).
- Plan timeline toolbar — month / quarter / year windows and pan controls.
- Workspace KPIs and descendant progress aggregation on the plan payload.

## Changed

- Activity planning dates — native date fields with PATCH from plan and detail surfaces.
- Kanban-aligned marker colours on plan timeline.

## Upgrade notes

- Prisma migrations add plan marker tables; applied automatically on core startup.
