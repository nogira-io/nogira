# NoGira 0.13.8

**Release date:** 2026-11-25

**Fix / feature:** Portfolio / activity hierarchy — independent **Add child** + **Link child**, workspace-relative Activities roots, My Work type icon. No GIF.

## Added

- Activity detail `capabilities.canAddChild` / `canLinkChild` / `linkChildHasCandidates` (backend-driven; UI does not hardcode workspace types or levels).
- **Link child** candidates: same-workspace eligible activities **and** Portfolio scheme-leaf → child-workspace scheme roots (existing bridge).
- Independent **+ Add child** and **+ Link child** on activity detail; section title **Child Activities**; empty Link → disabled + tooltip.
- My Work Kanban cards: activity type icon + color beside the key (board parity).

## Changed

- Activities `listMode=roots`: rows with `parentId` null **or** parent in another workspace (linked Portfolio children appear on child-workspace Activities).
- Portfolio `scope=portfolioRollup` honors the same list filters as child workspaces (Myself / type / status).

## Fixed

- Linked child-workspace work hidden on Activities while visible on Plan/Kanban (**NGB-117** Part B).
- Portfolio rollup ignoring Myself / type / status filters (**NGB-117** Part A).

## Out of scope (unchanged)

- Sample installer compose stays on **`latest`**.
- Creating new activities inside a picked child workspace from Portfolio (Link existing only).

## Upgrade notes

- Sample installer `docker-compose.yml` stays on **`latest`**.
- Promote matching **core + ui + worker + mcp** images together.
- Smoke: Portfolio leaf → Link child only; non-leaf / Marketing–Dev level &gt; 0 → both buttons; scheme leaf → neither; linked Marketing root still lists under Marketing Activities roots.
