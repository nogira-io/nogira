# Security Policy

If you discover a security vulnerability in NoGira software:

1. **Do not** create a public issue or post details online.
2. Email **security@nogira.co.uk** with:
   - A clear description of the issue
   - Steps to reproduce
   - A suggested mitigation if possible

We will acknowledge receipt within 48 hours and provide updates until resolved.
Responsible disclosure is appreciated and may be credited after remediation.
